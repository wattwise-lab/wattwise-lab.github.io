All four units describe the same area; the mu figure uses the definition in the formula table below.

Formula

Convert the source value to square metres, then divide by the target unit's square-metre factor: target = value × source factor ÷ target factor.

UnitSquare metres per unit
Square metre (m²)1
Square foot (ft²)0.09290304
Acre4,046.8564224
Mu666.6667

The square-foot and acre factors are exact international definitions. The mu factor 666.6667 m² is the commonly used Chinese definition (1 mu = 2000/3 m², rounded here); cadastral and local land units may follow other definitions.

Worked example

100 m² ÷ 0.09290304 m²/ft² = 1,076.391042 ft². The same 100 m² is 100 ÷ 4,046.8564224 = 0.024711 acre, and 100 ÷ 666.6667 = 0.150000 mu (shown as 0.15 after display rounding; the unrounded value is 0.14999999 because the mu factor itself is rounded).

Scope and limitations

Negative areas are rejected as invalid. Display values are rounded to 6 decimal places; the underlying calculation is not rounded. The mu definition varies by place and era, so for legal or cadastral use confirm the definition your authority applies — this page uses 666.6667 m² per mu throughout.

FAQ

What is a mu?

A Chinese area unit. This page uses the common modern definition 1 mu = 666.6667 m² (2000/3 m²). Older or local definitions differ, so check before using it for land documents.

How many square feet are in a square metre?

1 m² = 10.76391041671 ft², because 1 ft² = 0.09290304 m² exactly.

How big is an acre?

One acre = 4,046.8564224 m², about 0.4047 hectares. An American football field (without end zones) is about 0.756 acre.

Why does the mu result show 0.15 instead of 0.14999999?

Display rounding to 6 decimal places. The full-precision value is kept for the reverse conversion shown in the chips.

Can I convert hectares?

Not on this page: the four units here are the ones the original tool offered. Convert hectares to square metres first (1 ha = 10,000 m²) and enter that value.
