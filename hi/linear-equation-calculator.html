गणित

रैखिक समीकरण कैलकुलेटर

ax + b = 0 को हल करें और इसकी ढलान और y-अंतःखंड से एक सीधी रेखा का निरीक्षण करें, जिसमें क्षैतिज रेखाएं और कोई अद्वितीय हल नहीं वाले समीकरण शामिल हैं।

वर्कस्पेस में जोड़ें

आपके मान

परिणाम आपके टाइप करते ही अपडेट हो जाते हैं। सभी गणनाएँ आपके ब्राउज़र में स्थानीय रूप से चलती हैं।

हल: x

—

रेखा: —x-अंतर्खंड: —y-अंतर्खंड: —

—

सूत्रहल किया गया उदाहरणदायरा और सीमाएँFAQ

सूत्र

ax + b = 0 के लिए, जहाँ a ≠ 0: x = −b ÷ a ढलान-अंतःखंड रूप y = mx + c वाली रेखा के लिए: ढलान m (ऊंचाई बटे चौड़ाई) है, y-अंतःखंड c (x = 0 पर मान) है, और x-अंतःखंड −c ÷ m (x का वह मान जहाँ y = 0, जब m ≠ 0) है। यदि a = 0 है, तो समीकरण ax + b = 0 का कोई हल नहीं है, जब तक कि b भी 0 न हो, इस स्थिति में प्रत्येक x एक हल होगा।

हल किया गया उदाहरण

3x + 6 = 0: x = −6 ÷ 3 = −2. जाँच: 3 × (−2) + 6 = 0. रेखा y = 2x + 3 के लिए: ढलान 2 है (x में प्रत्येक 1 चरण के लिए y 2 बढ़ता है), y-अंतःखंड 3 है, और x-अंतःखंड −3 ÷ 2 = −1.50 है। रेखा y-अक्ष को (0, 3) पर और x-अक्ष को (−1.50, 0) पर काटती है।

दायरा और सीमाएँ

यह पृष्ठ एक चर वाले एकल रैखिक समीकरणों को हल करता है और सीधी रेखाओं का वर्णन करता है। यह द्विघात समीकरणों (द्विघात समीकरण कैलकुलेटर देखें), समीकरणों की प्रणालियों (समीकरणों की प्रणाली कैलकुलेटर देखें), या असमानताओं को हल नहीं करता है - हालांकि y = mx + c का x-अंतःखंड आपको बताता है कि mx + c का चिह्न कहाँ बदलता है। इनपुट केवल संख्याएँ हैं; भिन्नों को दशमलव में ही दर्ज किया जाना चाहिए, और बहुत बड़े या छोटे गुणांकों के प्रदर्शन में सटीकता कम हो सकती है, भले ही अंतर्निहित अंकगणित मानक दोहरी परिशुद्धता हो।

FAQ

यदि a = 0 हो तो क्या होगा?

तब समीकरण b = 0 होगा, जिसमें x शामिल नहीं है। यदि b भी 0 है, तो x का प्रत्येक मान इसे संतुष्ट करता है (समीकरण एक तत्समक समीकरण है)। यदि b 0 नहीं है, तो x का कोई भी मान इसे संतुष्ट नहीं करता है। पृष्ठ शून्य से भाग देने के बजाय यह बताता है कि कौन सा मामला लागू होता है।

ढलान का वास्तव में क्या अर्थ है?

वृद्धि/लंबाई: x में 1 की वृद्धि होने पर y में कितना परिवर्तन होता है। 2 का ढलान का अर्थ है कि y प्रति x चरण 2 बढ़ता है; −0.5 का ढलान का अर्थ है कि y प्रति x चरण आधा इकाई गिरता है। 0 का ढलान एक क्षैतिज रेखा है।

मैं x-अंतःखंड कैसे पढ़ूँ?

यह वह बिंदु है जहाँ रेखा x-अक्ष को काटती है, यानी जहाँ y = 0 होता है। y = 2x + 3 के लिए, 2x + 3 = 0 को हल करने पर x = −1.50 प्राप्त होता है — यह वही गणना है जो समीकरण हल करने वाले टूल में होती है, और यह कोई संयोग नहीं है: अंतःखंड समीकरण के हल ही होते हैं।

क्या मैं भिन्न दर्ज कर सकता हूँ?

इन्हें दशमलव के रूप में दर्ज करें (1/2 को 0.5 के रूप में)। पृष्ठ दो दशमलव स्थानों तक परिणाम दिखाता है; 1/3 जैसे आवर्ती दशमलव 0.33 के रूप में प्रदर्शित होते हैं, इसलिए सटीक भिन्नात्मक गणना के लिए भिन्न रूप को साथ में रखें।

ढलान-अंतःखंड और मानक रूप में क्या अंतर है?

ढलान-अंतःखंड रूप y = mx + c ढलान और y-अंतःखंड को सीधे दर्शाता है। मानक रूप Ax + By = C उसी रेखा का पुनर्व्यवस्थित रूप है: m = −A ÷ B और c = C ÷ B (जब B ≠ 0)। यह पृष्ठ ढलान-अंतःखंड रूप में कार्य करता है।

जाँच क्यों महत्वपूर्ण है?

हल को वापस प्रतिस्थापित करने से चिह्न त्रुटियाँ पकड़ी जाती हैं, जो रैखिक समीकरणों में सबसे आम गलती है। 3x + 6 = 0 के लिए, x = −2 सही है क्योंकि 3(−2) + 6 = 0; x = 2 से 12 प्राप्त होगा, न कि 0।

संबंधित उपकरण

  • द्विघात समीकरण कैलकुलेटर ax² + bx + c = 0 के मूल
  • भिन्न कैलकुलेटर — दशमलव के बिना सटीक भिन्न अंकगणित
  • प्रतिशत कैलकुलेटर — प्रतिशत परिवर्तन और अनुपात
