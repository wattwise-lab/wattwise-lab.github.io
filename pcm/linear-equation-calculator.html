Formula

For ax + b = 0 with a ≠ 0: x = −b ÷ a. For line in slope-intercept form y = mx + c: slope na m (rise over run), y-intercept na c (value at x = 0), and x-intercept na −c ÷ m (x value where y = 0, when m ≠ 0). If a = 0, equation ax + b = 0 no get solution unless b also 0, in which case every x na solution.

Example wey show the calculation

3x + 6 = 0: x = −6 ÷ 3 = −2. Check: 3 × (−2) + 6 = 0. For line y = 2x + 3: slope na 2 (y rise 2 for each 1 step in x), y-intercept na 3, and x-intercept na −3 ÷ 2 = −1.50. Line cross y-axis at (0, 3) and x-axis at (−1.50, 0).

Where e fit work and limits

This page solve single linear equations in one variable and describe straight lines. E no dey solve quadratics (see quadratic equation calculator), systems of equations (see system of equations calculator), or inequalities — though x-intercept of y = mx + c dey tell you where sign of mx + c change. Inputs na plain numbers; fractions must enter as decimals, and very large or tiny coefficients fit lose precision in display, though underlying arithmetic na standard double precision.

Questions wey people dey ask often

Wetin if a = 0?

Then equation na b = 0, which no involve x. If b also 0, every value of x satisfy am (equation na identity). If b not 0, no value of x satisfy am. Page say which case apply instead of dividing by zero.

Wetin slope actually mean?

Rise over run na how much y change when x increase by 1. Slope of 2 mean say y rise 2 for each x step; slope of −0.5 mean say y drop half a unit per x step. Slope of 0 na horizontal line.

How I fit read the x-intercept?

Na where line cross x-axis, i.e. where y = 0. For y = 2x + 3, solving 2x + 3 = 0 give x = −1.50 — same calculation as equation solver, which no be coincidence: intercepts na just solutions of equation.

I fit enter fractions?

Enter dem as decimals (1/2 as 0.5). The page dey show results to two decimals. Repeating decimals like 1/3 go show as 0.33, so keep the fraction form too if you need exact fraction work.

How slope-intercept form differ from standard form?

Slope-intercept form y = mx + c dey show the slope and y-intercept directly. Standard form Ax + By = C na the same line after rearranging: m = −A ÷ B and c = C ÷ B (when B ≠ 0). This page dey use slope-intercept form.

Why e matter to check the answer?

Put the answer back inside the equation to catch sign mistakes, wey dey common for linear equations. For 3x + 6 = 0, x = −2 work because 3(−2) + 6 = 0; x = 2 go give 12, no be 0.
