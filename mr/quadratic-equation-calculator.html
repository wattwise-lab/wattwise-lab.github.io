वर्गसमीकरण कॅल्क्युलेटर

ax² + bx + c बरोबर शून्य हे समीकरण सोडवा: दोन्ही मुळे, विवेचक, शिरोबिंदू, आणि जेव्हा विवेचक नकारात्मक असतो तेव्हा संमिश्र मुळे.

वर्कस्पेसमध्ये जोडा

इनपुट मूल्ये

तुम्ही टाईप करताच निकाल अपडेट होतात. कॅल्क्युलेट बटण नाही. सर्व गणना तुमच्या ब्राउझरमध्ये स्थानिकरित्या केल्या जातात.

मुळे

—

विवेचक: —शिरोबिंदू x: —

—

सूत्रसोडवलेले उदाहरणव्याप्ती आणि मर्यादाFAQ

सूत्र

x = [−b ± √(b² − 4ac)] ÷ 2a. विवेचक D = b² − 4ac मुळाचा प्रकार ठरवतो: D > 0 दोन भिन्न वास्तव मुळे देतो, D = 0 एक पुनरावृत्त मूळ देतो, D < 0 दोन संमिश्र मुळे देतो. शिरोबिंदू (वळणबिंदू) x = −b ÷ 2a येथे असतो.

सोडवलेले उदाहरण

x² − 5x + 6 = 0: a = 1, b = −5, c = 6. विवेचक = (−5)² − 4 × 1 × 6 = 25 − 24 = 1. मुळे = [5 ± √1] ÷ 2, म्हणून x = 3 आणि x = 2. पडताळणी: 3² − 15 + 6 = 0 आणि 2² − 10 + 6 = 0. शिरोबिंदू x = 2.5 येथे आहे.

व्याप्ती आणि मर्यादा

शून्येतर a वर्गसमीकरण दर्शवतो. a शून्य असल्यास पृष्ठ रेषीय किंवा स्थिर समीकरणाची स्थिती दाखवते. निकाल सामान्यतः 12 सार्थक अंकांत दाखवले जातात; जवळची मुळे वेगळी ओळखण्यासाठी ही संख्या 17 पर्यंत वाढते. अतिशय लहान किंवा मोठ्या मूल्यांसाठी वैज्ञानिक संकेतन वापरले जाते. दशांश इनपुटची परिशुद्धता निकालाच्या अचूकतेवर मर्यादा घालते, विशेषतः पुनरावृत्त मुळांजवळ. समर्थित मर्यादेबाहेरील संख्यांसाठी अनंत किंवा चुकीचे शून्य दाखवण्याऐवजी त्रुटी दाखवली जाते.

W. Kahan (2004), Qdrtcs

FAQ

जर a शून्य असेल तर काय?

नंतर bx + c = 0 हे समीकरण सोडवा. जर b अशून्य असेल, तर x = −c ÷ b. जर b आणि c दोन्ही शून्य असतील, तर प्रत्येक वास्तव x लागू होतो; जर b शून्य असेल पण c नसेल, तर कोणतेही उत्तर नाही.

विवेचक मला काय सांगतो?

मुळे वास्तव आहेत की नाही आणि किती: धन म्हणजे दोन भिन्न वास्तव मुळे, शून्य म्हणजे एक पुनरावृत्त मूळ, ऋण म्हणजे एकही वास्तव मूळ नाही — परवलय कधीही x-अक्षाला छेदत नाही.

संमिश्र मुळे म्हणजे काय?

जेव्हा विवेचक ऋण असतो, तेव्हा मुळांमध्ये i (−1 चे वर्गमूळ) समाविष्ट असते. x² + 2x + 5 = 0 साठी मुळे −1 + 2i आणि −1 − 2i आहेत. ही संमिश्र संख्यांवरील खरी उत्तरे आहेत, फक्त ती वास्तविक x-अक्षावरील बिंदू नाहीत.

दोन मुळे का?

घात 2 असलेल्या बहुपदीला बहुगुणता मोजल्यास दोन मुळे असतात. ती एकरूप असू शकतात किंवा संमिश्र जोडी बनवू शकतात; बहुगुणता मोजल्यावर नेहमी दोन मुळे असतात.

त्याऐवजी अवयव पाडावेत का?

जेव्हा मुळे लहान पूर्णांक असतात, जसे की (x − 3)(x − 2 या उदाहरणात, तेव्हा अवयव पाडणे अधिक जलद होते. अवयव पाडणे स्पष्ट नसतानासुद्धा, हे सूत्र नेहमीच लागू होते.

शिरोबिंदू महत्त्वाचा आहे का?

हा परवलयाचा वळणबिंदू आहे: जेव्हा a > 0 असते तेव्हा किमान, आणि जेव्हा a < 0 असते तेव्हा कमाल. जेव्हा दोन वास्तव मुळे अस्तित्वात असतात, तेव्हा तो त्यांच्या अगदी मध्यभागी असतो.
