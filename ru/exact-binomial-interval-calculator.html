Формула

Используйте L = B⁻¹(α/2;k,n−k+1) и U = B⁻¹(1−α/2;k+1,n−k). k — число успехов, n — число испытаний. Для доверительного уровня в виде доли c задайте α = 1−c; B⁻¹ — бета-квантиль. Граничные случаи: k = 0 → L = 0 и k = n → U = 1.
