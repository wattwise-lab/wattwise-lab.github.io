Fórmula

Para una altura de al menos 5 pies (60 pulgadas o 152.4 cm), el peso de referencia en kg = base + 2.3 × (altura en pulgadas − 60). La base es 50 kg para hombres y 45.5 kg para mujeres. Altura en pulgadas = altura en cm ÷ 2.54. Esta página no extrapola por debajo de 152.4 cm.

Ejemplo resuelto

Altura 170 cm, mujer: 170 ÷ 2.54 = 66.93 pulgadas, que son 6.93 pulgadas por encima de 5 pies. Peso de referencia = 45.5 + 2.3 × 6.93 = 45.5 + 15.94 = 61.4 kg (135.4 lb). La base masculina a la misma altura da 65.9 kg, y la BMI en 61.4 kg y 170 cm es 21.3. Utilice el ejemplo de reinicio anterior para reproducir este resultado.

Alcance y limitaciones

Devine es una ecuación de referencia histórica de altura y sexo asociada con la literatura sobre dosificación de medicamentos. No considera la composición corporal, la edad, el embarazo ni el estado de salud individual. Esta herramienta educativa para adultos no selecciona un peso para la dosificación clínica, no calcula una dosis ni determina un peso objetivo saludable. Debajo de 152.4 cm no muestra ninguna estimación, en lugar de inventar un peso mínimo constante.

FAQ

¿Es este mi peso ideal?

No. Es un número de referencia basado en la altura, proveniente de una fórmula de dosificación. El peso adecuado para cada persona depende de factores que esta página no modela.

¿Por qué difieren hombres y mujeres?

La fórmula utiliza bases diferentes: 50 kg para hombres, 45.5 kg para mujeres, con el mismo 2.3 kg por pulgada por encima de 5 pies.

¿Qué sucede por debajo de 5 pies?

Esta página no calcula para alturas inferiores a 5 pies (152.4 cm). Asignar el mismo peso base a todos los adultos de menor estatura ocultaría la limitación de la fórmula. Para decidir una dosis o tomar una decisión de salud se necesita una evaluación clínica individual.

¿Cómo se relaciona esto con BMI?

La tabla muestra el BMI en el peso de referencia para su altura, para que pueda ver dónde se ubica el número de referencia dentro de los rangos estándar de BMI.

¿Se almacenan mis datos?

No. Este cálculo se ejecuta localmente en su navegador y los valores que ingresa no se envían a una base de datos CalcMintly.

¿Debería intentar alcanzar este número?

Tómelo como un punto de referencia para la discusión, no como un objetivo. Cualquier objetivo de peso debe tener en cuenta las circunstancias personales que la fórmula no puede considerar.
