计算公式

对于ax+b=0且a≠0：x=-b÷a。对于斜率截距形式 y = mx + c 的直线：斜率为 m（上升超过运行），y 截距为 c（x = 0 处的值），x 截距为 −c ÷ m（当 m ≠ 0 时，y = 0 时的 x 值）。如果 a = 0，则方程 ax + b = 0 无解，除非 b 也是 0，在这种情况下每个 x 都是解。

计算示例

3x + 6 = 0:x = - 6 ÷ 3 = - 2。检查：3 × (−2) + 6 = 0。对于直线 y = 2x + 3：斜率为 2（x 中每 1 一步，y 上升 2），y 截距为 3，x 截距为 −3 ÷ 2 = −1.50。该线在 (0, 3) 处与 y 轴相交，在 (−1.50, 0) 处与 x 轴相交。

适用范围与限制

本页求解一个变量中的单个线性方程并描述直线。它不能求解二次方程（请参阅二次方程计算器）、方程组（请参阅方程组计算器）或不等式 - 尽管 y = mx + c 的 x 截距确实可以告诉您 mx + c 的符号在哪里发生变化。输入是普通数字；分数必须以小数形式输入，尽管底层算术是标准双精度，但非常大或很小的系数可能会在显示时丢失精度。

常见问题

如果a=0怎么办？

那么方程为b=0，其不涉及x。如果 b 也是 0，则 x 的每个值都满足它（方程是恒等式）。如果 b 不是 0，则没有 x 值满足它。该页面说明了适用哪种情况，而不是除以零。

斜率实际上意味着什么？

上升超过运行：当x增加1时y改变多少。斜率 2 表示 y 每 x 步爬升 2；斜率 -0.5 意味着 y 每 x 步下降半个单位。斜率0是一条水平线。

如何读取 x 截距？

这是线与x轴相交的地方，即y=0的地方。对于 y = 2x + 3，求解 2x + 3 = 0 得到 x = −1.50 — 与方程求解器的计算相同，这并非巧合：截距只是方程的解。

我可以输入分数吗？

将它们输入为小数（1/2 作为 0.5）。页面显示结果精确到两位小数；重复小数（例如 1/3）显示为 0.33，因此对于精确的分数运算，请将分数形式放在旁边。

斜率-截距和标准形式之间有什么区别？

斜率-截距形式y=mx+c直接暴露斜率和y-截距。标准形式 Ax + By = C 是同一行的重新排列：m = −A ÷ B 和 c = C ÷ B（当 B ≠ 0 时）。该页面以斜截形式工作。

为什么支票很重要？

将解代回会导致符号错误，这是线性方程中最常见的错误。对于 3x + 6 = 0，x = −2 检验成立，因为 3(−2) + 6 = 0； x = 2 将给出 12，而不是 0。
