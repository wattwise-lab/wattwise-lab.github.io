रेषीय समीकरण कॅल्क्युलेटर

ax + b = 0 सोडवा आणि उतार व y-अक्षावरील छेदावरून सरळ रेषेची वैशिष्ट्ये पहा. यात आडव्या रेषा आणि एकमेव उत्तर नसलेली समीकरणेही समाविष्ट आहेत.

सूत्रसोडवलेले उदाहरणव्याप्ती आणि मर्यादाFAQ

सूत्र

ax + b = 0 साठी, जिथे a ≠ 0: x = −b ÷ a. y = mx + c या स्लोप-इंटरसेप्ट फॉर्ममधील रेषेसाठी: स्लोप म्हणजे m (उंची भागिले रुंदी), y-इंटरसेप्ट म्हणजे c (x = 0 येथील मूल्य), आणि x-इंटरसेप्ट म्हणजे −c ÷ m (x चे मूल्य जेथे y = 0, जेव्हा m ≠ 0). जर a = 0 असेल, तर ax + b = 0 या समीकरणाला कोणताही उपाय नाही, जोपर्यंत b सुद्धा 0 नसेल, अशावेळी प्रत्येक x हा एक उपाय असतो.

सोडवलेले उदाहरण

3x + 6 = 0: x = −6 ÷ 3 = −2. पडताळणी: 3 × (−2) + 6 = 0. y = 2x + 3 या रेषेसाठी: उतार 2 आहे ​​(x च्या प्रत्येक 1 पायरीसाठी y, 2 ने वाढतो), y-अक्ष छेदबिंदू 3 आहे, आणि x-अक्ष छेदबिंदू −3 ÷ 2 = −1.50 आहे. ही रेषा y-अक्षाला (0, 3) येथे आणि x-अक्षाला (−1.50, 0) येथे छेदते.

व्याप्ती आणि मर्यादा

हे पृष्ठ एका चलातील एकल रेषीय समीकरणे सोडवते आणि सरळ रेषांचे वर्णन करते. हे वर्गसमीकरणे (वर्गसमीकरण कॅल्क्युलेटर पहा), समीकरण प्रणाली (समीकरण प्रणाली कॅल्क्युलेटर पहा), किंवा असमानता सोडवत नाही — जरी y = mx + c चा x-अक्ष छेदबिंदू तुम्हाला mx + c चे चिन्ह कोठे बदलते हे सांगतो. इनपुट साधे अंक आहेत; अपूर्णांक दशांश स्वरूपात प्रविष्ट करणे आवश्यक आहे, आणि खूप मोठे किंवा लहान सहगुणक प्रदर्शित करताना अचूकता गमावू शकतात, जरी मूळ अंकगणित मानक डबल प्रिसिजन असले तरी.

FAQ

जर a = 0 असेल तर काय?

तर समीकरण b = 0 आहे, ज्यामध्ये x चा समावेश नाही. जर b हे 0 सुद्धा असेल, तर x चे प्रत्येक मूल्य ते समीकरण पूर्ण करते (समीकरण एक नित्यसमानता आहे). जर b हे 0 नसेल, तर x चे कोणतेही मूल्य ते समीकरण पूर्ण करत नाही. शून्याने भागण्याऐवजी कोणती स्थिती लागू होते हे पृष्ठ सांगते.

स्लोपचा (उतार) नेमका अर्थ काय आहे?

राइज ओव्हर रन (उंची भागिले रुंदी): जेव्हा x मध्ये 1 ने वाढ होते, तेव्हा y मध्ये किती बदल होतो. 2 च्या स्लोपचा अर्थ असा आहे की प्रत्येक x पायरीवर y, 2 ने वर चढतो; −0.5 च्या स्लोपचा अर्थ असा आहे की प्रत्येक x पायरीवर y अर्ध्या एककाने खाली येतो. 0 चा स्लोप ही एक आडवी रेषा असते.

मी x-इंटरसेप्ट कसा वाचू?

जिथे रेषा x-अक्षाला छेदते, म्हणजेच जिथे y = 0. y = 2x + 3 साठी, 2x + 3 = 0 हे समीकरण सोडवल्यास x = −1.50 मिळते — हे समीकरण सोडवणाऱ्याच्या गणनेसारखेच आहे, आणि हा काही योगायोग नाही: इंटरसेप्ट्स म्हणजे समीकरणाची उत्तरेच असतात.

मी अपूर्णांक टाकू शकतो का?

ते दशांश स्वरूपात टाका (1/2 साठी 0.5). हे पान दोन दशांश स्थळांपर्यंत निकाल दाखवते; 1/3 सारखे आवर्ती दशांश 0.33 असे दिसतात, म्हणून अचूक अपूर्णांक कामासाठी अपूर्णांकाचे स्वरूप सोबत ठेवा.

स्लोप-इंटरसेप्ट आणि स्टँडर्ड फॉर्ममध्ये काय फरक आहे?

उतार-खंड रूप y = mx + c हे उतार आणि y-खंड थेट दर्शवते. प्रमाणित रूप Ax + By = C हे त्याच रेषेची पुनर्रचित मांडणी आहे: m = −A ÷ B आणि c = C ÷ B (जेव्हा B ≠ 0). हे पान उतार-खंड रूपात कार्य करते.

पडताळणी का महत्त्वाची आहे?

उत्तर परत ठेवल्याने चिन्हांच्या चुका लक्षात येतात, जी रेषीय समीकरणांमधील सर्वात सामान्य चूक आहे. 3x + 6 = 0 साठी, x = −2 बरोबर आहे कारण 3(−2) + 6 = 0; x = 2 घेतल्यास 0 ऐवजी 12 मिळेल.

संबंधित साधने
