Keep control of your calculation data.

Effective 2026-10-30. Calculators run locally without a user account or a CalcMintly application database.

Site operator

CalcMintly is operated by an individual. For calculator corrections or privacy requests, contact hello@calcmintly.com. Please do not include sensitive personal information in email.

Inputs and local text parsing

Inputs, scenario snapshots and workspace links normally stay in page memory. The merchant profit planner also has an explicit Save action that stores its plan, including entered assumptions, in this browser until you clear it. The natural-language fill feature uses local text rules; your text is not sent to an AI service. Reloading normally clears inputs. A shared calculation link can restore values you deliberately included.

Preferences and optional device counts

Language and saved layouts use localStorage on this browser. Layouts store calculator choices and order, not inputs. Optional device-only usage counts are off by default, save calculator visit counts only and are cleared when disabled. These counts are not sent to CalcMintly.

Sharing, exports and printing

Layout links contain tool choices only. Calculation-share buttons include selected inputs in the URL fragment; anyone receiving that link can read them. CSV files and print reports contain the values you export. Review them before sharing. Health calculator input sharing is disabled.

Hosting and outside websites

The hosting provider may process IP addresses, request times, browser details and requested paths for delivery and security. URL fragments are not part of ordinary HTTP requests. Third-party reference links follow their own privacy policies.

Analytics, advertising and contact

Behavioral analytics, advertising and nonessential tracking cookies are not enabled. No consent banner is shown for tracking that does not exist. Email sent by you is processed by the mail providers; avoid private financial or health details. Use the contact address for privacy or data-rights requests.

Local data controls

Saved layouts, language preferences and optional device-only usage history are stored in this browser. Use this button to remove CalcMintly local data.
