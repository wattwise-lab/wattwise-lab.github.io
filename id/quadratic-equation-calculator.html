Rumus

x = [−b ± √(b² − 4ac)] ÷ 2a. Diskriminan D = b² − 4ac menentukan tipe akar: D > 0 memberikan dua akar real yang berbeda, D = 0 memberikan satu akar berulang, D < 0 memberikan dua akar kompleks. Titik puncak (titik balik) berada di x = −b ÷ 2a.

Contoh soal

x² − 5x + 6 = 0: a = 1, b = −5, c = 6. Diskriminan = (−5)² − 4 × 1 × 6 = 25 − 24 = 1. Akar = [5 ± √1] ÷ 2, jadi x = 3 dan x = 2. Periksa: 3² − 15 + 6 = 0 dan 2² − 10 + 6 = 0. Puncaknya berada di x = 2.5.

Cakupan dan batasan

Nilai a yang bukan nol mendefinisikan persamaan kuadrat. Jika a adalah nol, halaman akan melaporkan kasus persamaan linear atau persamaan konstan. Hasil biasanya menunjukkan 12 angka signifikan, meningkat menjadi 17 untuk membedakan akar yang berdekatan. Nilai yang sangat kecil atau besar menggunakan notasi ilmiah. Presisi input desimal masih membatasi akurasi, terutama di dekat akar yang berulang. Besaran numerik yang tidak didukung menunjukkan kesalahan alih-alih tak terhingga atau nol palsu.

W. Kahan (2004), Qdrtcs

FAQ

Bagaimana jika a adalah nol?

Kemudian selesaikan bx + c = 0. Jika b bukan nol, maka x = −c ÷ b. Jika b dan c sama-sama nol, maka setiap bilangan real x dapat digunakan; jika b nol tetapi c bukan nol, maka tidak ada solusi.

Apa yang disampaikan oleh data diskriminan kepada saya?

Apakah akarnya nyata dan berapa banyak: positif berarti dua akar nyata yang berbeda, nol berarti satu akar berulang, negatif berarti tidak ada akar nyata — parabola tidak pernah memotong sumbu x.

Apa itu akar kompleks?

Ketika diskriminan negatif, akarnya melibatkan i (akar kuadrat dari −1). Untuk x² + 2x + 5 = 0 akarnya adalah −1 + 2i dan −1 − 2i. Ini adalah solusi sejati pada bilangan kompleks, hanya saja bukan titik pada sumbu x riil.

Mengapa ada dua akar?

Polinomial berderajat 2 mempunyai dua akar jika dihitung dengan multiplisitasnya. Keduanya dapat berimpit atau berupa pasangan kompleks; dengan memperhitungkan multiplisitas, jumlahnya selalu dua.

Haruskah saya memfaktorkan saja?

Pemfaktoran lebih cepat ketika akarnya berupa bilangan bulat kecil, seperti pada contoh (x − 3)(x − 2). Rumusnya selalu berlaku, termasuk ketika pemfaktoran tidak jelas.

Apakah titik puncak penting?

Ini adalah titik balik parabola: minimum ketika a > 0, maksimum ketika a < 0. Letaknya tepat di tengah-tengah antara dua akar real ketika keduanya ada.
