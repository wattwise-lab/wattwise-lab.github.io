Формула

Для ax + b = 0 с a ≠ 0: x = −b ÷ a. Для прямой в форме y = mx + c с угловым коэффициентом наклон равен m (отношение подъема к перемещению), точка пересечения с осью y равна c (значение в точке x = 0), а точка пересечения с осью x равна −c ÷ m (значение x, где y = 0, когда m ≠ 0). Если a = 0, уравнение ax + b = 0 не имеет решения, если только b также не равно 0, в этом случае каждое x является решением.

Пример решения

3x + 6 = 0: x = −6 ÷ 3 = −2. Проверка: 3 × (−2) + 6 = 0. Для прямой y = 2x + 3: наклон равен 2 (y увеличивается на 2 при каждом шаге 1 по x), точка пересечения с осью y равна 3, а точка пересечения с осью x равна −3 ÷ 2 = −1.50. Прямая пересекает ось y в точке (0, 3) и ось x в точке (−1.50, 0).

Область применения и ограничения

Эта страница решает линейные уравнения с одной переменной и описывает прямые линии. Она не решает квадратные уравнения (см. калькулятор квадратных уравнений), системы уравнений (см. калькулятор систем уравнений) или неравенства — хотя точка пересечения с осью x прямой y = mx + c показывает, где меняется знак mx + c. Входные данные — обычные числа; Дроби необходимо вводить в десятичном формате, а очень большие или малые коэффициенты могут терять точность при отображении, хотя базовая арифметика является стандартной двойной точностью.

FAQ

Что, если a = 0?

Тогда уравнение имеет вид b = 0, которое не включает x. Если b также равно 0, то каждое значение x удовлетворяет ему (уравнение является тождеством). Если b не равно 0, то ни одно значение x не удовлетворяет ему. На странице указано, какой случай применим, вместо деления на ноль.

Что на самом деле означает наклон?

Отношение подъема к перемещению: насколько изменяется y при увеличении x на 1. Наклон 2 означает, что y поднимается на 2 за шаг x; наклон −0.5 означает, что y падает на полединицы за шаг x. Наклон 0 — это горизонтальная линия.

Как читать точку пересечения с осью x?

Это точка пересечения прямой с осью x, т.е. точка, где y = 0. Для уравнения y = 2x + 3 решение уравнения 2x + 3 = 0 дает x = −1.50 — тот же расчет, что и в решателе уравнения, что не случайно: точки пересечения с осями — это просто решения уравнения.

Можно ли вводить дроби?

Вводите их в виде десятичных дробей (1/2 как 0.5). На странице отображаются результаты с точностью до двух десятичных знаков; повторяющиеся десятичные дроби, такие как 1/3, отображаются как 0.33, поэтому для точных вычислений с дробями сохраняйте дробную форму рядом.

В чем разница между формой уравнения прямой с угловым коэффициентом и стандартной формой?

Форма уравнения y = mx + c с угловым коэффициентом и свободным членом напрямую показывает угловой коэффициент и точку пересечения с осью y. Стандартная форма Ax + By = C — это та же самая прямая, переставленная местами: m = −A ÷ B и c = C ÷ B (когда B ≠ 0). На этой странице используется форма уравнения с угловым коэффициентом и свободным членом.

Почему важна проверка?

Подстановка решения обратно позволяет выявить ошибки в знаках, наиболее распространенную ошибку в линейных уравнениях. Для 3x + 6 = 0, x = −2 совпадает, потому что 3(−2) + 6 = 0; x = 2 даст 12, а не 0.
