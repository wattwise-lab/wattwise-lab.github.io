Formule

Comptez les dates de début à fin, en incluant les deux dates limites. Excluez les jours de repos hebdomadaires de votre modèle, puis soustrayez le montant des jours fériés que vous avez indiqué. Ne déduisez que les jours fériés qui seraient normalement des jours ouvrables.

Exemple résolu

Du 1 septembre 2026 au 30 septembre 2026 inclus : 30 jours calendaires, dont 22 jours ouvrables et 8 jours de week-end. Avec 0 jours fériés saisis, le nombre de jours ouvrés nets est de 22. Utilisez l’exemple de réinitialisation ci-dessus pour reproduire ce résultat, puis saisissez le nombre de jours fériés inclus dans la plage, le cas échéant.

Portée et limites

Les jours fériés et les fermetures spécifiques à l’organisation sont NOT automatiquement supprimés : aucun tableau de jours fériés nationaux ou régionaux n’est utilisé, car les calendriers des jours fériés varient selon les juridictions et évoluent avec le temps. Saisissez vous-même le nombre de jours fériés inclus dans votre plage, ou laissez la valeur à 0 pour un décompte des jours ouvrables uniquement. Les années bissextiles sont gérées par le calendrier. Si la date de fin est antérieure à la date de début, aucun décompte n’est affiché.

Utilise le calendrier grégorien proleptique et le calcul des dates uniquement, indépendamment de l'heure d'été. Pour les années et les mois complets, le jour du mois d'origine est utilisé, ajusté au dernier jour valide si nécessaire. D'autres conventions d'anniversaire peuvent différer ; ceci ne constitue pas une détermination de l'âge légal.

FAQ

Quels jours sont comptabilisés ? Choisissez le modèle de jours de repos hebdomadaires. Par défaut, le samedi et le dimanche sont exclus. La plage de dates inclut les deux extrémités.

Les déductions pour jours fériés doivent concerner uniquement les jours ouvrables, sans double comptage des jours de repos hebdomadaires. Les déductions fractionnaires peuvent représenter des demi-journées ; le total ne peut excéder le nombre de jours ouvrables.
