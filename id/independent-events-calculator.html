Perbandingan skenario

Hingga tiga cuplikan di tab ini. Memuat satu akan menggantikan input saat ini.

Rumus

Untuk kejadian independen, gunakan P = ∏pᵢ untuk semua kejadian terjadi dan 1−P untuk kejadian yang tidak semua terjadi. pᵢ adalah pecahan probabilitas yang dimasukkan. Komplemennya berarti setidaknya satu kejadian gagal, bukan berarti setiap kejadian gagal.

Kalikan probabilitas kejadian independen dan temukan komplemennya.

Contoh soal

Probabilitas dari 0 ke 1
0.5, 0.2, 0.8
Probabilitas semuanya terjadi
8 %
Probabilitas setidaknya satu gagal
92 %

Cakupan dan batasan

Perkalian membutuhkan independensi. Kejadian terkait membutuhkan model gabungan atau bersyarat.

Input diperiksa untuk nilai yang hilang dan rentang yang diizinkan. Hasil di luar rentang numerik terbatas tidak ditampilkan. Pembulatan memengaruhi tampilan, sementara perhitungan menggunakan presisi numerik model.

Periksa satuan dan asumsi Anda sebelum mengandalkan hasilnya. Mengubah label tidak mengkonversi mata uang atau satuan fisik.
