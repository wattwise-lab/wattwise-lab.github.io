Rumus

Untuk ax + b = 0 dengan a ≠ 0: x = −b ÷ a. Untuk garis dalam bentuk kemiringan-perpotongan y = mx + c: kemiringannya adalah m (naik dibagi lari), perpotongan y adalah c (nilai pada x = 0), dan perpotongan x adalah −c ÷ m (nilai x di mana y = 0, ketika m ≠ 0). Jika a = 0, persamaan ax + b = 0 tidak memiliki solusi kecuali b juga 0, dalam hal ini setiap x adalah solusi.

Contoh soal

3x + 6 = 0: x = −6 ÷ 3 = −2. Periksa: 3 × (−2) + 6 = 0. Untuk garis y = 2x + 3: kemiringannya adalah 2 (y naik 2 untuk setiap 1 langkah dalam x), perpotongan sumbu y adalah 3, dan perpotongan sumbu x adalah −3 ÷ 2 = −1.50. Garis tersebut memotong sumbu y di (0, 3) dan sumbu x di (−1.50, 0).

Cakupan dan batasan

Halaman ini menyelesaikan persamaan linear tunggal dalam satu variabel dan menjelaskan garis lurus. Halaman ini tidak menyelesaikan persamaan kuadrat (lihat kalkulator persamaan kuadrat), sistem persamaan (lihat kalkulator sistem persamaan), atau pertidaksamaan — meskipun perpotongan sumbu x dari y = mx + c memberi tahu Anda di mana tanda mx + c berubah. Input berupa angka biasa; Pecahan harus dimasukkan sebagai desimal, dan koefisien yang sangat besar atau sangat kecil dapat kehilangan presisi dalam tampilan, meskipun aritmatika yang mendasarinya adalah presisi ganda standar.

FAQ

Bagaimana jika a = 0?

Maka persamaannya adalah b = 0, yang tidak melibatkan x. Jika b juga 0, setiap nilai x memenuhi persamaan tersebut (persamaan tersebut adalah identitas). Jika b bukan 0, tidak ada nilai x yang memenuhi persamaan tersebut. Halaman tersebut menjelaskan kasus mana yang berlaku, alih-alih membagi dengan nol.

Apa sebenarnya arti kemiringan?

Kenaikan dibagi lari: seberapa besar perubahan y ketika x meningkat sebesar 1. Kemiringan 2 berarti y naik 2 per langkah x; kemiringan −0.5 berarti y turun setengah unit per langkah x. Kemiringan 0 adalah garis horizontal.

Bagaimana cara membaca titik potong sumbu x?

Titik potong sumbu x adalah titik di mana garis memotong sumbu x, yaitu di mana y = 0. Untuk y = 2x + 3, penyelesaian 2x + 3 = 0 memberikan x = −1.50 — perhitungan yang sama dengan penyelesai persamaan, yang bukan kebetulan: titik potong hanyalah solusi dari persamaan.

Dapatkah saya memasukkan pecahan?

Masukkan sebagai desimal (1/2 sebagai 0.5). Halaman ini menampilkan hasil hingga dua desimal; desimal berulang seperti 1/3 ditampilkan sebagai 0.33, jadi untuk pekerjaan pecahan yang tepat, simpan bentuk pecahan di sampingnya.

Apa perbedaan antara bentuk kemiringan-titik potong dan bentuk standar?

Bentuk kemiringan-perpotongan y = mx + c memperlihatkan kemiringan dan perpotongan y secara langsung. Bentuk standar Ax + By = C adalah garis yang sama yang disusun ulang: m = −A ÷ B dan c = C ÷ B (ketika B ≠ 0). Halaman ini bekerja dalam bentuk kemiringan-perpotongan.

Mengapa pengecekan itu penting?

Substitusi solusi kembali akan menangkap kesalahan tanda, kesalahan paling umum dalam persamaan linear. Untuk 3x + 6 = 0, x = −2 sudah benar karena 3(−2) + 6 = 0; x = 2 akan menghasilkan 12, bukan 0.
