Fórmula

Para ax + b = 0 com a ≠ 0: x = −b ÷ a. Para uma reta na forma reduzida da equação y = mx + c: o coeficiente angular é m (variação vertical sobre variação horizontal), o coeficiente linear é c (o valor em x = 0) e ​​o coeficiente linear é −c ÷ m (o valor de x onde y = 0, quando m ≠ 0). Se a = 0, a equação ax + b = 0 não tem solução a menos que b também seja 0, caso em que todo x é uma solução.

Exemplo prático

3x + 6 = 0: x = −6 ÷ 3 = −2. Verificação: 3 × (−2) + 6 = 0. Para a reta y = 2x + 3: a inclinação é 2 (y sobe 2 para cada 1 passo em x), a intersecção com o eixo y é 3 e a intersecção com o eixo x é −3 ÷ 2 = −1.50. A reta cruza o eixo y em (0, 3) e o eixo x em (−1.50, 0).

Escopo e limitações

Esta página resolve equações lineares simples em uma variável e descreve retas. Ela não resolve equações quadráticas (consulte a calculadora de equações quadráticas), sistemas de equações (consulte a calculadora de sistemas de equações) ou inequações — embora a intersecção com o eixo x de y = mx + c indique onde o sinal de mx + c muda. As entradas são números simples; As frações devem ser inseridas como decimais e coeficientes muito grandes ou muito pequenos podem perder precisão na exibição, embora a aritmética subjacente seja de dupla precisão padrão.

FAQ

E se a = 0?

Então a equação é b = 0, que não envolve x. Se b também for 0, todo valor de x a satisfaz (a equação é uma identidade). Se b não for 0, nenhum valor de x a satisfaz. A página indica qual caso se aplica em vez de dividir por zero.

O que a inclinação realmente significa?

Subida sobre deslocamento horizontal: quanto y muda quando x aumenta em 1. Uma inclinação de 2 significa que y sobe 2 por passo de x; uma inclinação de −0.5 significa que y cai meia unidade por passo de x. Uma inclinação de 0 é uma linha horizontal.

Como interpreto a intersecção com o eixo x?

É onde a reta cruza o eixo x, ou seja, onde y = 0. Para y = 2x + 3, resolvendo 2x + 3 = 0, obtemos x = −1.50 — o mesmo cálculo que o solucionador de equações, o que não é coincidência: as intersecções com o eixo x são apenas soluções da equação.

Posso inserir frações?

Insira-as como decimais (1/2 como 0.5). A página mostra os resultados com duas casas decimais; decimais periódicos, como 1/3, são exibidos como 0.33, portanto, para cálculos exatos com frações, mantenha a forma fracionária ao lado.

Qual é a diferença entre a forma reduzida da equação da reta e a forma geral da equação da reta?

A forma reduzida da equação da reta y = mx + c expõe diretamente o coeficiente angular e o coeficiente linear. A forma padrão Ax + By = C é a mesma reta rearranjada: m = −A ÷ B e c = C ÷ B (quando B ≠ 0). Esta página funciona na forma reduzida da equação da reta.

Por que a verificação é importante?

Substituir a solução de volta detecta erros de sinal, o erro mais comum em equações lineares. Para 3x + 6 = 0, x = −2 está correto porque 3(−2) + 6 = 0; x = 2 daria 12, não 0.
