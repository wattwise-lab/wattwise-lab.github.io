What changed in CalcMintly

Release: unified calculator library · 2026-10-30

500 distinct calculators

This release includes a pocket keypad, a scientific keypad, practical calculators across nine categories and three original planning scenarios. Language pages and embedded views are not counted as separate tools.

A clearer workspace

Search every tool directly, start with a goal pack, compare up to four cards and create unit-compatible live links. Local text rules can preview inputs for six core tools before filling them. Layout saving stores tool choices and order only.

Calculation corrections

Rent-versus-buy now compares equal starting resources and invests monthly cash-flow differences. Calendar tools use date-only arithmetic for month ends and leap years. Probability tools preserve small tails and check convergence. Sources, examples and limitations remain visible beside the calculators.

Reading verification claims

Automated numerical checks cover recorded examples and selected boundaries. They do not prove every possible input, clinical validity, worldwide popularity, search indexing, real-user performance percentiles or every browser version.
