Rechner für lineare Gleichungen

Formel

Für ax + b = 0 mit a ≠ 0 gilt: x = −b ÷ a. Für eine Gerade in der Form y = mx + c (Steigungsabschnitt) ist die Steigung m (Höhenunterschied geteilt durch horizontale Entfernung), der y-Achsenabschnitt c (der Wert bei x = 0) und der x-Achsenabschnitt −c ÷ m (der x-Wert, bei dem y = 0 gilt, wenn m ≠ 0). Wenn a = 0, hat die Gleichung ax + b = 0 keine Lösung, es sei denn, b ist auch 0. In diesem Fall ist jedes x eine Lösung.

Durchgerechnetes Beispiel

3x + 6 = 0: x = −6 ÷ 3 = −2. Probe: 3 × (−2) + 6 = 0. Für die Gerade y = 2x + 3 gilt: Die Steigung ist 2 (y steigt 2 für jeden 1 Schritt von x), der y-Achsenabschnitt ist 3 und der x-Achsenabschnitt ist −3 ÷ 2 = −1.50. Die Gerade schneidet die y-Achse bei (0, 3) und die x-Achse bei (−1.50, 0).

Anwendungsbereich und Grenzen

Diese Seite löst einfache lineare Gleichungen mit einer Variablen und beschreibt Geraden. Sie löst keine quadratischen Gleichungen (siehe den Rechner für quadratische Gleichungen), Gleichungssysteme (siehe den Rechner für Gleichungssysteme) oder Ungleichungen – obwohl der x-Achsenabschnitt von y = mx + c angibt, wo sich das Vorzeichen von mx + c ändert. Eingaben sind einfache Zahlen. Brüche müssen als Dezimalzahlen eingegeben werden, und sehr große oder sehr kleine Koeffizienten können bei der Anzeige an Genauigkeit verlieren, obwohl die zugrundeliegende Arithmetik Standard-Doppelgenauigkeit ist.

FAQ

Was ist, wenn a = 0?

Dann lautet die Gleichung b = 0, die x nicht enthält. Wenn b auch 0 ist, erfüllt jeder Wert von x die Gleichung (die Gleichung ist eine Identität). Wenn b nicht 0 ist, erfüllt kein Wert von x die Gleichung. Auf der Seite wird angegeben, welcher Fall zutrifft, anstatt durch Null zu teilen.

Was bedeutet die Steigung genau?

Steigung geteilt durch horizontale Entfernung: wie stark sich y ändert, wenn x um 1 zunimmt. Eine Steigung von 2 bedeutet, dass y pro x-Schritt um 2 steigt; eine Steigung von −0.5 bedeutet, dass y pro x-Schritt um eine halbe Einheit fällt. Eine Steigung von 0 entspricht einer horizontalen Geraden.

Wie lese ich den x-Achsenabschnitt ab?

Er ist der Punkt, an dem die Gerade die x-Achse schneidet, also dort, wo y = 0 gilt. Für y = 2x + 3 ergibt die Lösung von 2x + 3 = 0 x = −1.50 – dieselbe Berechnung wie beim Gleichungslöser. Das ist kein Zufall: Achsenabschnitte sind einfach Lösungen der Gleichung.

Kann ich Brüche eingeben?

Geben Sie sie als Dezimalzahlen ein (1/2 als 0.5). Die Seite zeigt die Ergebnisse auf zwei Dezimalstellen genau an; periodische Dezimalzahlen wie 1/3 werden als 0.33 angezeigt. Geben Sie daher für exakte Bruchrechnungen die Bruchdarstellung separat ein.

Was ist der Unterschied zwischen der Steigungs-Achsenabschnittsform und der allgemeinen Form?

Die Steigungsform y = mx + c gibt Steigung und y-Achsenabschnitt direkt an. Die allgemeine Form Ax + By = C ist dieselbe Gerade, nur umgestellt: m = −A ÷ B und c = C ÷ B (wenn B ≠ 0). Diese Seite verwendet die Steigungsform.

Warum ist die Überprüfung wichtig?

Durch Einsetzen der Lösung lassen sich Vorzeichenfehler aufdecken, der häufigste Fehler bei linearen Gleichungen. Für 3x + 6 = 0 ist x = −2 korrekt, da 3(−2) + 6 = 0; x = 2 würde 12 und nicht 0 ergeben.
