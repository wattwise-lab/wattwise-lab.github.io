Fórmula

Para altura de pelo menos 5 pés (60 polegadas ou 152.4 cm), o peso de referência em kg = base + 2.3 × (altura em polegadas − 60). A base é 50 kg para homens e 45.5 kg para mulheres. Altura em polegadas = altura em cm ÷ 2.54. Esta página não extrapola abaixo de 152.4 cm.

Exemplo prático

Altura 170 cm, feminina: 170 ÷ 2.54 = 66.93 polegadas, que é 6.93 polegadas acima de 5 pés. Peso de referência = 45.5 + 2.3 × 6.93 = 45.5 + 15.94 = 61.4 kg (135.4 lb). A base masculina na mesma altura dá 65.9 kg, e o BMI em 61.4 kg e 170 cm é 21.3. Use o exemplo de redefinição acima para reproduzir este resultado.

Escopo e limitações

A equação de Devine é uma equação histórica de referência para altura e sexo, associada à literatura sobre dosagem de medicamentos. Ela não leva em consideração a composição corporal, a idade, a gravidez ou o estado de saúde individual. Esta ferramenta educacional para adultos não seleciona um peso para dosagem clínica, não calcula uma dose nem determina um peso-alvo saudável. Abaixo de 152.4 cm, ela não mostra nenhuma estimativa, em vez de inventar um peso mínimo constante.

FAQ

Este é o meu peso ideal?

Não. É um número de referência baseado na altura, proveniente de uma fórmula de dosagem. O peso adequado para um indivíduo depende de fatores que esta página não considera.

Por que homens e mulheres são diferentes?

A fórmula usa bases diferentes — 50 kg para homens, 45.5 kg para mulheres — com o mesmo 2.3 kg por polegada acima de 5 pés.

O que acontece abaixo de 5 pés?

Esta página não calcula para alturas inferiores a 5 pés (152.4 cm). Apresentar o mesmo peso base para todos os adultos de menor estatura ocultaria a limitação da fórmula. Utilize uma avaliação clínica individual quando for necessário tomar uma decisão sobre dosagem ou saúde.

Como isso se relaciona com BMI?

A tabela mostra o BMI no peso de referência para sua altura, para que você possa ver onde o número de referência se situa nos intervalos padrão de BMI.

Meus dados estão armazenados?

Não. Este cálculo é executado localmente no seu navegador e os valores que você insere não são enviados para um banco de dados CalcMintly.

Devo tentar atingir esse número?

Trate-o como um ponto de referência para discussão, não como uma meta. Qualquer meta de peso deve levar em conta as circunstâncias pessoais que a fórmula não pode prever.
