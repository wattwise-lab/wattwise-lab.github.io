Sous-réseaux enfants

—

Estimation du projet à partir des paramètres saisis. Aucun service, appareil, tarif ou réseau externe n'est sollicité.

Comparaison de scénarios

Jusqu'à trois instantanés dans cet onglet. Le chargement d'un instantané remplace les entrées actuelles.

Formule

Utilisez S = 2^(c−p) et A = 2^(128−c). p est le préfixe parent, c est le préfixe enfant, S est le nombre de sous-réseaux enfants et A est le nombre d'adresses par sous-réseau enfant.

Compte les préfixes enfants IPv6 de même longueur à l'aide d'entiers exacts.

Exemple résolu

Longueur du préfixe parent
48
Longueur du préfixe enfant
64
Sous-réseaux enfants
65536
Adresses par sous-réseau enfant
18446744073709551616
