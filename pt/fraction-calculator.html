Fórmula

Adição: a/b + c/d = (ad + bc) / bd. Subtração: a/b − c/d = (ad − bc) / bd. Multiplicação: a/b × c/d = ac / bd. Divisão: a/b ÷ c/d = ad / bc. Em todos os casos, divida o numerador e o denominador resultantes pelo seu maior divisor comum (GCD) para simplificar, mantendo qualquer sinal de menos no numerador.

Exemplo prático

1/2 + 1/3 = (1×3 + 1×2) / (2×3) = 5/6. O GCD de 5 e 6 é 1, então 5/6 já é o mais simples, e seu valor decimal é 0.833333… (mostrado como 0.8333). Use o exemplo Reset acima para reproduzir este resultado e, em seguida, substitua os valores pelos seus.

Escopo e limitações

As entradas podem ser números inteiros, negativos ou decimais finitos. Os valores decimais são convertidos em frações de base -10 antes da aritmética inteira exata e da simplificação. O navegador lê as entradas como números JavaScript, portanto, os dígitos além de sua precisão numérica não podem ser recuperados. Os denominadores não podem ser zero e a divisão também exige um segundo numerador diferente de zero. Os resultados são arredondados para 4 casas decimais apenas para exibição; a fração subjacente é exata para entradas inteiras.

FAQ

O que acontece se um denominador for zero?

O resultado não é exibido. Uma fração com denominador zero não está definida, portanto a página pede um denominador diferente de zero em vez de inventar um número.

Como o resultado é simplificado?

Pelo máximo divisor comum: por exemplo, 4/6 divide por GCD 2 para dar 2/3. O sinal é mantido no numerador, portanto, −1/2 e 1/−2 são exibidos como −1/2.

Por que o decimal às vezes se repete?

Frações como 1/3 não têm um decimal finito exato. O decimal mostrado é arredondado para 4 casas decimais (0.3333); a própria fração, 1/3, é a resposta exata.

Posso usar frações negativas?

Sim. Insira um numerador (ou denominador) negativo; o resultado é normalizado para que o denominador permaneça positivo.

O que é um número misto?

Uma parte inteira mais uma fração, por exemplo, 7/3 = 2 1/3. É mostrado para resultados impróprios; frações próprias e números inteiros são mostrados como são.
