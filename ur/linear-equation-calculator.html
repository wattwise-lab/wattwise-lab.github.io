فارمولاکام کی مثالدائرہ اور حدودFAQ

فارمولا

ax + b = 0 کے لئے a ≠ 0 کے ساتھ: x = −b ÷ a۔ slope-intercept فارم y = mx + c میں ایک لائن کے لیے: ڈھلوان m ہے (رائز اوور رن)، y-انٹرسیپٹ c ہے (قدر x = 0)، اور x-انٹرسیپٹ ہے −c ÷m (x قدر جہاں y = 0، جب m ≠ 0)۔ اگر a = 0، مساوات ax + b = 0 کا کوئی حل نہیں ہے جب تک کہ b بھی 0 نہ ہو، اس صورت میں ہر x ایک حل ہے۔

کام کی مثال

3x + 6 = 0: x = −6 ÷ 3 = −2۔ چیک کریں: 3 × (−2) + 6 = 0۔ لائن y = 2x + 3 کے لیے: ڈھلوان 2 ہے (x میں ہر 1 قدم کے لیے y بڑھتا ہے 2)، y-انٹرسیپٹ 3 ہے، اور x-انٹرسیپٹ ہے −3 ÷ 2 = −1.50۔ لائن y-axis کو (0, 3) اور x-axis کو (−1.50, 0) پر کراس کرتی ہے۔

دائرہ اور حدود

یہ صفحہ واحد لکیری مساوات کو ایک متغیر میں حل کرتا ہے اور سیدھی لکیروں کو بیان کرتا ہے۔ یہ quadratics (کواڈراٹک مساوات کیلکولیٹر دیکھیں)، مساوات کے نظام (مساوات کیلکولیٹر کا نظام دیکھیں)، یا عدم مساوات کو حل نہیں کرتا ہے - حالانکہ y = mx + c کا x-intercept آپ کو بتاتا ہے کہ mx + c کا نشان کہاں تبدیل ہوتا ہے۔ ان پٹ سادہ نمبر ہیں؛ فریکشنز کو اعشاریہ کے طور پر درج کیا جانا چاہیے، اور بہت بڑے یا چھوٹے گتانک ڈسپلے میں درستگی کھو سکتے ہیں، حالانکہ بنیادی ریاضی معیاری ڈبل درستگی ہے۔

FAQ

کیا ہوگا اگر a = 0

پھر مساوات b = 0 ہے، جس میں x شامل نہیں ہے۔ اگر b بھی 0 ہے تو x کی ہر قدر اسے مطمئن کرتی ہے (مساوات ایک شناخت ہے)۔ اگر b 0 نہیں ہے تو x کی کوئی قدر اسے مطمئن نہیں کرتی ہے۔ صفحہ بتاتا ہے کہ کون سا کیس صفر سے تقسیم کرنے کے بجائے لاگو ہوتا ہے۔

ڈھلوان کا اصل مطلب کیا ہے؟

رائز اوور رن: جب x 1 سے بڑھتا ہے تو y کتنا بدلتا ہے۔ 2 کی ڈھلوان کا مطلب ہے y چڑھائی 2 فی x قدم؛ −0.5 کی ڈھلوان کا مطلب ہے y آدھا یونٹ فی x قدم گرتا ہے۔ 0 کی ڈھلوان ایک افقی لکیر ہے۔

میں ایکس انٹرسیپٹ کو کیسے پڑھ سکتا ہوں؟

یہ وہ جگہ ہے جہاں لائن ایکس محور کو عبور کرتی ہے، یعنی جہاں y = 0۔ y = 2x + 3 کے لیے، 2x + 3 = 0 کو حل کرنے سے x = −1.50 ملتا ہے — وہی حساب جو مساوات کو حل کرنے والا ہے، جو کوئی اتفاقی نہیں ہے: وقفے صرف مساوات کے حل ہیں۔

کیا میں کسر درج کر سکتا ہوں؟

انہیں اعشاریہ کے طور پر درج کریں (1/2 بطور 0.5)۔ صفحہ دو اعشاریہ پر نتائج دکھاتا ہے۔ دہرائے جانے والے اعشاریہ جیسے کہ 1/3 کو 0.33 کے طور پر ظاہر کریں، لہذا قطعی کسری کام کے لیے کسر کی شکل کو ساتھ رکھیں۔

ڈھلوان انٹرسیپٹ اور معیاری شکل میں کیا فرق ہے؟

Slope-intercept فارم y = mx + c ڈھلوان اور y-انٹرسیپٹ کو براہ راست ظاہر کرتا ہے۔ معیاری شکل Ax + By = C ایک ہی لائن کو دوبارہ ترتیب دیا گیا ہے: m = −A ÷ B اور c = C ÷ B (جب B ≠ 0)۔ یہ صفحہ ڈھلوان انٹرسیپٹ فارم میں کام کرتا ہے۔

چیک کی اہمیت کیوں ہے؟

حل کو تبدیل کرنے سے نشانی کی غلطیاں آتی ہیں، لکیری مساوات میں سب سے عام غلطی۔ 3x + 6 = 0 کے لیے، x = −2 چیک آؤٹ کرتا ہے کیونکہ 3(−2) + 6 = 0; x = 2 12 دے گا، 0 نہیں۔
