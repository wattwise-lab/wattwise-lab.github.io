Fórmula

Use L = B⁻¹(α/2;k,n−k+1) y U = B⁻¹(1−α/2;k+1,n−k). k es el número de éxitos y n el de ensayos. Para el nivel de confianza expresado como fracción c, use α = 1−c; B⁻¹ es el cuantil beta. Aplique los casos límite k = 0 → L = 0 y k = n → U = 1.
