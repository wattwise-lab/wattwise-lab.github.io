Formule

Pour ax + b = 0 avec a ≠ 0 : x = −b ÷ a. Pour une droite de forme réduite y = mx + c : la pente est m (variation verticale divisée par la variation horizontale), l'ordonnée à l'origine est c (la valeur de x = 0), et l'abscisse à l'origine est −c ÷ m (la valeur de x pour laquelle y = 0, lorsque m ≠ 0). Si a = 0, l'équation ax + b = 0 n'a pas de solution sauf si b = 0, auquel cas toute valeur de x est solution.

Exemple résolu

3x + 6 = 0 : x = −6 ÷ 3 = −2. Vérification : 3 × (−2) + 6 = 0. Pour la droite d'équation y = 2x + 3 : la pente est 2 (y augmente de 2 pour chaque 1 variation de x), l'ordonnée à l'origine est 3 et l'abscisse à l'origine est −3 ÷ 2 = −1.50. La droite coupe l'axe des ordonnées au point (0, 3) et l'axe des abscisses au point (−1.50, 0).

Portée et limites

Cette page résout des équations linéaires simples à une inconnue et décrit les droites. Elle ne résout pas les équations du second degré (voir le calculateur d'équations du second degré), les systèmes d'équations (voir le calculateur de systèmes d'équations) ni les inéquations — bien que l'abscisse à l'origine de y = mx + c indique où le signe de mx + c change. Les entrées sont des nombres simples. Les fractions doivent être saisies sous forme décimale. Les coefficients très grands ou très petits peuvent entraîner une perte de précision à l'affichage, même si les calculs sous-jacents sont effectués en double précision standard.

FAQ

Que se passe-t-il si a = 0 ?

L'équation est alors b = 0, qui ne dépend pas de x. Si b est également 0, toute valeur de x satisfait l'équation (il s'agit d'une identité). Si b n'est pas 0, aucune valeur de x ne la satisfait. La page indique le cas applicable au lieu de diviser par zéro.

Que signifie la pente ?

Déplacement vertical : variation de y lorsque x augmente de 1. Une pente de 2 signifie que y augmente de 2 par unité de x ; une pente de −0.5 signifie que y diminue d'une demi-unité par unité de x. Une pente de 0 correspond à une droite horizontale.

Comment lire l'abscisse à l'origine ?

C'est le point où la droite coupe l'axe des abscisses, c'est-à-dire là où y = 0. Pour y = 2x + 3, la résolution de 2x + 3 = 0 donne x = −1.50 — soit le même calcul que celui du solveur d'équations, ce qui n'est pas un hasard : les ordonnées à l'origine sont simplement des solutions de l'équation.

Puis-je saisir des fractions ?

Saisissez-les sous forme décimale (1/2 par 0.5). La page affiche les résultats avec deux décimales ; les décimales périodiques, comme 1/3, s'affichent par 0.33. Pour des calculs fractionnaires précis, conservez la forme fractionnaire à côté.

Quelle est la différence entre la forme réduite et la forme canonique ?

La forme réduite y = mx + c donne directement la pente et l'ordonnée à l'origine. La forme développée Ax + By = C correspond à la même droite réarrangée : m = −A ÷ B et c = C ÷ B (lorsque B ≠ 0). Cette page utilise la forme réduite.

Pourquoi le chèque est-il important ?

La substitution de la solution permet de détecter les erreurs de signe, l'erreur la plus fréquente dans les équations linéaires. Pour 3x + 6 = 0, x = −2 est correct car 3(−2) + 6 = 0 ; x = 2 donnerait 12, et non 0.
