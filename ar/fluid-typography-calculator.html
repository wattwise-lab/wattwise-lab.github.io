تعبير CSS للتحديد

—

القيمة CSS المُولَّدة هي قيمة ابتدائية. يُفضَّل استخدام وحدات نص نسبية عند الاقتضاء، واختبار التكبير والتصغير، وتغيير حجم النص، وتجاوز النص.

مقارنة السيناريوهات

ما يصل إلى ثلاث لقطات في هذه الصفحة. يؤدي تحميل إحداها إلى استبدال المدخلات الحالية.

الصيغة

استخدم m = 100(f₁−f₀)/(v₁−v₀) و b = f₀−mv₀/100. حجم الخط المرن هو clamp(f₀, b + m×vw, f₁)؛ يشير f إلى أحجام الخطوط، ويشير v إلى عرض نافذة العرض.

قم بإنشاء مقياس خطي CSS بين عرضي منفذي العرض.

مثال عملي

الحد الأدنى لحجم الخط (بكسل)
16
الحد الأقصى لحجم الخط (بكسل)
24
الحد الأدنى لعرض نافذة العرض (بكسل)
400
الحد الأقصى لعرض نافذة العرض (بكسل)
1200
تعبير CSS للتحديد
clamp(16px, calc(12px + 1vw), 24px)
معامل نافذة العرض
1 vw
نقطة تقاطع البكسل
12 px

النطاق والقيود

القيمة CSS المُولَّدة هي قيمة ابتدائية. يُفضَّل استخدام وحدات نص نسبية عند الاقتضاء، واختبار التكبير والتصغير، وتغيير حجم النص، وتجاوز النص.

يتم التحقق من المدخلات بحثًا عن القيم المفقودة والنطاقات المسموح بها. لا يتم عرض أي نتيجة خارج النطاق العددي المحدد. يؤثر التقريب على العرض، بينما تستخدم العملية الحسابية الدقة العددية للنموذج.

تحقق من وحداتك وافتراضاتك قبل الاعتماد على النتيجة. تغيير التسمية لا يُحوّل العملة أو الوحدة الفيزيائية.
