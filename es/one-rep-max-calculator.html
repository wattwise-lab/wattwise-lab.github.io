Estimación de Epley

—

Solo una predicción, no una recomendación para intentar levantar el peso. Limitado a 1–10 repeticiones técnicamente correctas; la fatiga, el tipo de ejercicio y el historial de entrenamiento afectan la precisión.

Comparación de escenarios

Hasta tres instantáneas en esta pestaña. Cargar una reemplaza las entradas actuales.

Fórmula

Para r > 1, use Epley E = w(1+r/30); para r = 1, use E = w. Brzycki usa B = 36w/(37−r). w es el peso levantado y r son las repeticiones completadas. Ambos resultados usan la unidad de peso.

Alcance y limitaciones

Solo una predicción, no una recomendación para intentar levantar el peso. Limitado a 1–10 repeticiones técnicamente correctas; la fatiga, el tipo de ejercicio y el historial de entrenamiento afectan la precisión.
