計算式

ax + b = 0 で a ≠ 0 の場合: x = −b ÷ a。傾き切片形式の直線 y = mx + c の場合: 傾きは m (上昇量÷水平移動量)、y 切片は c (x = 0 の値)、x 切片は −c ÷ m (m ≠ 0 の場合、y = 0 の x 値)。a = 0 の場合、b が 0 でない限り、方程式 ax + b = 0 には解がありません。この場合、すべての x が解となります。

実例

3x + 6 = 0: x = −6 ÷ 3 = −2。確認: 3 × (−2) + 6 = 0。直線 y = 2x + 3 について、傾きは 2 (x が 1 ずつ増加するごとに y は 2 上昇します)、y 切片は 3、x 切片は −3 ÷ 2 = −1.50 です。この直線は y 軸と (0, 3) で、x 軸と (−1.50, 0) で交わります。

適用範囲と制限

このページでは、1 変数の線形方程式を解き、直線を記述します。二次方程式 (二次方程式計算機を参照)、連立方程式 (連立方程式計算機を参照)、不等式は解けません。ただし、y = mx + c の x 切片は、mx + c の符号が変わる位置を示します。入力は数値です。分数は小数で入力する必要があります。係数が非常に大きい場合や非常に小さい場合、表示精度が低下する可能性がありますが、基となる演算は標準の倍精度演算です。

FAQ

a = 0 の場合はどうなりますか？

この場合、方程式は b = 0 となり、x は含まれません。b が 0 でもある場合、x のすべての値がこの方程式を満たします（この方程式は恒等式です）。b が 0 でない場合、x のどの値もこの方程式を満たしません。このページでは、ゼロ除算の代わりにどちらの場合が適用されるかを説明しています。

傾きは実際には何を意味しますか？

上昇量÷水平移動量：x が 1 だけ増加したときの y の変化量です。傾きが 2 の場合、x が 1 ステップ増えるごとに y は 2 だけ上昇します。傾きが −0.5 の場合、x が 1 ステップ増えるごとに y は 0.5 単位だけ下降します。傾きが 0 の場合は水平線です。

x切片はどのように読み取ればよいですか？

x切片とは、直線がx軸と交わる点、つまりy = 0となる点のことです。y = 2x + 3の場合、2x + 3 = 0を解くと、x = −1.50となります。これは方程式ソルバーの計算結果と同じです。切片は方程式の解に他なりません。

分数を入力できますか？

小数で入力してください（1/2は0.5）。このページには小数点以下2桁までの結果が表示されます。1/3のような循環小数は0.33と表示されるため、正確な分数計算を行うには、分数形式を併記してください。

傾き切片形式と標準形式の違いは何ですか？

傾き切片形 y = mx + c は、傾きと y 切片を直接表します。標準形 Ax + By = C は、同じ式を変形したものです。m = −A ÷ B、c = C ÷ B (B ≠ 0 の場合)。このページは傾き切片形で動作します。

なぜ確認が重要なのでしょうか？

解を代入し直すことで、線形方程式で最もよくある間違いである符号の誤りを検出できます。3x + 6 = 0 の場合、x = −2 は 3(−2) + 6 = 0 となるため正しいです。x = 2 では 12 となり、0 にはなりません。
