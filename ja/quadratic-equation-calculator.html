計算式

x = [−b ± √(b² − 4ac)] ÷ 2a。判別式D = b² − 4acによって根の種類が決定されます。D > 0は2つの異なる実根を与え、D = 0は1つの重複根を与え、D < 0は2つの複素根を与えます。頂点（転換点）はx = −b ÷ 2aにあります。

実例

x² − 5x + 6 = 0: a = 1, b = −5, c = 6.判別式 = (−5)² − 4 × 1 × 6 = 25 − 24 = 1。根 = [5 ± √1] ÷ 2、したがって x = 3 および x = 2。確認: 3² − 15 + 6 = 0 および 2² − 10 + 6 = 0。頂点は x = 2.5 です。

適用範囲と制限

ゼロ以外の a は二次方程式を定義します。a がゼロの場合、ページには線形方程式または定数方程式の場合が表示されます。結果は通常 12 桁の有効数字で表示され、近い根を区別するために 17 まで増加します。非常に小さい値または大きい値は科学的記数法で表示されます。小数点入力の精度は、特に重複根の近くで、依然として精度を制限します。サポートされていない数値は、無限大または偽のゼロの代わりにエラーとして表示されます。

W. Kahan (2004), Qdrtcs

FAQ

aがゼロの場合はどうなりますか？

次に、bx + c = 0 を解きます。b がゼロでない場合、x = −c ÷ b となります。b と c の両方がゼロの場合、すべての実数 x が解となります。b がゼロで c がゼロでない場合、解はありません。

判別式は何を示していますか？

根が実数かどうか、またいくつあるかを示します。正の場合は2つの異なる実数根、ゼロの場合は1つの重複根、負の場合は実数根がないことを意味します。放物線はx軸と交わりません。

複素根とは何ですか？

判別式が負の場合、根にはi（−1の平方根）が含まれます。 x² + 2x + 5 = 0 の根は −1 + 2i と −1 − 2i です。これらは複素数体上の真の解ですが、実数軸上の点ではありません。

なぜ根が2つあるのか？

次数が 2 の多項式には、重複度を含めて二つの根があります。同じ根が重なる場合も、複素数の対になる場合もありますが、重複度を含めた根の数は常に二つです。

因数分解した方が良いでしょうか？

根が小さな整数の場合、例えば (x − 3)(x − 2) のように、因数分解の方が速いです。因数分解が明らかでない場合でも、この公式は常に有効です。

頂点は重要ですか？

これは放物線の転換点であり、a > 0のときに最小値、a < 0のときに最大値となる。実数解が存在する場合、この転換点は2つの実数解のちょうど中間に位置する。
