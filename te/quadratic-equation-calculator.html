గణితం

వర్గ సమీకరణ కాలిక్యులేటర్

ax² + bx + c = 0 సమీకరణాన్ని సాధించండి: రెండు మూలాలు, విచక్షణ, శీర్షం, మరియు విచక్షణ రుణాత్మకంగా ఉన్నప్పుడు సంక్లిష్ట మూలాలు.

సూత్రం

x = [−b ± √(b² − 4ac)] ÷ 2a. విచక్షణ D = b² − 4ac మూలం రకాన్ని నిర్ణయిస్తుంది: D > 0 రెండు విభిన్న వాస్తవ మూలాలను ఇస్తుంది, D = 0 ఒక పునరావృత మూలాన్ని ఇస్తుంది, D < 0 రెండు సంక్లిష్ట మూలాలను ఇస్తుంది. శీర్షం (మలుపు బిందువు) x = −b ÷ 2a వద్ద ఉంటుంది.

పనిచేసిన ఉదాహరణ

x² − 5x + 6 = 0: a = 1, b = −5, c = 6. విచక్షణ = (−5)² − 4 × 1 × 6 = 25 − 24 = 1. మూలాలు = [5 ± √1] ÷ 2, కాబట్టి x = 3 మరియు x = 2. సరిచూడండి: 3² − 15 + 6 = 0 మరియు 2² − 10 + 6 = 0. శీర్షం x = 2.5 వద్ద ఉంది.

పరిధి మరియు పరిమితులు

శూన్యం కాని 'a' ఒక వర్గ సమీకరణాన్ని సూచిస్తుంది. ఒకవేళ 'a' శూన్యమైతే, ఆ పేజీ రేఖీయ లేదా స్థిర-సమీకరణ సందర్భాన్ని నివేదిస్తుంది. ఫలితాలు సాధారణంగా 12 సార్థక అంకెలను చూపుతాయి, దగ్గరి మూలాలను వేరు చేయడానికి ఇవి 17 వరకు పెరుగుతాయి. చాలా చిన్న లేదా పెద్ద విలువలు శాస్త్రీయ సంకేత పద్ధతిని ఉపయోగిస్తాయి. దశాంశ ఇన్‌పుట్ కచ్చితత్వం ఇప్పటికీ ఖచ్చితత్వాన్ని పరిమితం చేస్తుంది, ముఖ్యంగా పునరావృతమయ్యే మూలాల దగ్గర. మద్దతు లేని సంఖ్యా పరిమాణాలు అనంతం లేదా తప్పుడు సున్నాకు బదులుగా ఒక దోషాన్ని చూపుతాయి.

W. Kahan (2004), Qdrtcs

FAQ

ఒకవేళ a సున్నా అయితే?

తరువాత bx + c = 0 ను సాధించండి. b శూన్యం కాకపోతే, x = −c ÷ b. b మరియు c రెండూ శూన్యమైతే, ప్రతి వాస్తవ x సరిపోతుంది; b శూన్యమై, c శూన్యం కాకపోతే, సాధన ఉండదు.

విచక్షణ నాకు ఏమి చెబుతుంది?

మూలాలు వాస్తవమైనవా మరియు ఎన్ని ఉన్నాయో: ధనాత్మకం అంటే రెండు విభిన్న వాస్తవ మూలాలు, సున్నా అంటే ఒక పునరావృత మూలం, రుణాత్మకం అంటే వాస్తవ మూలాలు లేవు — పరావలయం ఎప్పుడూ x-అక్షాన్ని దాటదు.

సంక్లిష్ట మూలాలు అంటే ఏమిటి?

విచక్షణ రుణాత్మకంగా ఉన్నప్పుడు, మూలాలలో i (−1 యొక్క వర్గమూలం) ఉంటుంది. x² + 2x + 5 = 0 సమీకరణానికి మూలాలు −1 + 2i మరియు −1 − 2i. అవి సంకీర్ణ సంఖ్యలపై నిజమైన సాధనలు, కానీ వాస్తవ x-అక్షంపై బిందువులు కావు.

రెండు మూలాలు ఎందుకు?

ఘాతం 2 గల బహుపదికి బహుళత్వాన్ని లెక్కిస్తే రెండు మూలాలు ఉంటాయి. అవి ఒకే మూలంగా కలవవచ్చు లేదా సంకీర్ణ జతగా ఉండవచ్చు; బహుళత్వంతో లెక్కిస్తే ఎప్పుడూ రెండు మూలాలే ఉంటాయి.

బదులుగా నేను కారణాంకాలుగా విభజించాలా?

మూలాలు చిన్న పూర్ణాంకాలుగా ఉన్నప్పుడు కారణాంకాలుగా విభజించడం వేగంగా ఉంటుంది, ఉదాహరణకు (x − 3)(x − 2). కారణాంకాలుగా విభజించడం స్పష్టంగా లేనప్పుడు కూడా ఈ సూత్రం ఎల్లప్పుడూ పనిచేస్తుంది.

శీర్షం (vertex) ముఖ్యమా?

ఇది పరాబోలా యొక్క మలుపు బిందువు: a > 0 అయినప్పుడు కనిష్ఠం, a < 0 అయినప్పుడు గరిష్ఠం. రెండు వాస్తవ మూలాలు ఉన్నప్పుడు, ఇది వాటికి సరిగ్గా మధ్యలో ఉంటుంది.

సంబంధిత సాధనాలు

  • భిన్నాల కాలిక్యులేటర్ — చేతితో మూలాలను తనిఖీ చేయడానికి ఖచ్చితమైన భిన్నాల అంకగణితం
  • పర్సెంటేజ్ కాలిక్యులేటర్ — రోజువారీ గణితం కోసం శాతం మార్పు మరియు వాటాలు
  • ప్రామాణిక విచలనం కాలిక్యులేటర్ దాని సగటు చుట్టూ ఒక దత్తాంశ సమితి యొక్క వ్యాప్తి

ఫలితాలు కేవలం అంచనాలు మాత్రమే మరియు ఇవి వృత్తిపరమైన సలహాగా పరిగణించబడవు.
