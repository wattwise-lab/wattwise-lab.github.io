Fórmula

Para ax + b = 0 con a ≠ 0: x = −b ÷ a. Para una recta en forma pendiente-ordenada al origen y = mx + c: la pendiente es m (cambio en el eje y sobre cambio en el eje x), la ordenada al origen es c (el valor en x = 0), y la ordenada al origen es −c ÷ m (el valor de x donde y = 0, cuando m ≠ 0). Si a = 0, la ecuación ax + b = 0 no tiene solución a menos que b también sea 0, en cuyo caso cualquier x es una solución.

Ejemplo resuelto

3x + 6 = 0: x = −6 ÷ 3 = −2. Comprobación: 3 × (−2) + 6 = 0. Para la recta y = 2x + 3: la pendiente es 2 (y aumenta 2 por cada 1 paso en x), la intersección con el eje y es 3 y la intersección con el eje x es −3 ÷ 2 = −1.50. La recta cruza el eje y en (0, 3) y el eje x en (−1.50, 0).

Alcance y limitaciones

Esta página resuelve ecuaciones lineales simples con una variable y describe rectas. No resuelve ecuaciones cuadráticas (consulte la calculadora de ecuaciones cuadráticas), sistemas de ecuaciones (consulte la calculadora de sistemas de ecuaciones) ni desigualdades, aunque la intersección con el eje x de y = mx + c indica dónde cambia el signo de mx + c. Las entradas son números simples; Las fracciones deben introducirse como decimales, y los coeficientes muy grandes o muy pequeños pueden perder precisión en la visualización, aunque la aritmética subyacente sea de doble precisión estándar.

FAQ

¿Qué ocurre si a = 0?

Entonces la ecuación es b = 0, que no incluye x. Si b también es 0, cualquier valor de x la satisface (la ecuación es una identidad). Si b no es 0, ningún valor de x la satisface. La página indica qué caso se aplica en lugar de dividir por cero.

¿Qué significa realmente la pendiente?

Relación entre ascenso y descenso: cuánto cambia y cuando x aumenta en 1. Una pendiente de 2 significa que y asciende 2 por cada paso de x; una pendiente de −0.5 significa que y desciende media unidad por cada paso de x. Una pendiente de 0 es una línea horizontal.

¿Cómo se lee la intersección con el eje x?

Es donde la recta cruza el eje x, es decir, donde y = 0. Para y = 2x + 3, al resolver 2x + 3 = 0 se obtiene x = −1.50, el mismo cálculo que el solucionador de ecuaciones, lo cual no es casualidad: las intersecciones son simplemente soluciones de la ecuación.

¿Puedo introducir fracciones?

Introdúzcalas como decimales (1/2 como 0.5). La página muestra los resultados con dos decimales; los decimales periódicos como 1/3 se muestran como 0.33, así que para trabajar con fracciones exactas, mantenga la forma fraccionaria junto a la recta.

¿Cuál es la diferencia entre la forma pendiente-ordenada al origen y la forma estándar?

La forma pendiente-ordenada al origen y = mx + c expone directamente la pendiente y la ordenada al origen. La forma estándar Ax + By = C es la misma recta reordenada: m = −A ÷ B y c = C ÷ B (cuando B ≠ 0). Esta página trabaja con la forma pendiente-ordenada al origen.

¿Por qué es importante la verificación?

Sustituir la solución de nuevo permite detectar errores de signo, el error más común en ecuaciones lineales. Para 3x + 6 = 0, x = −2 es correcto porque 3(−2) + 6 = 0; x = 2 daría 12, no 0.
