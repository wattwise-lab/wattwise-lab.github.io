Três passos simples

  1. Adicione uma calculadora por nome ou finalidade. Use "Substituir" em um cartão para alterá-la.
  2. Edite os números de exemplo. Cada calculadora é atualizada independentemente.
  3. Use «Enviar resultado» para copiar uma vez. Use ligações dinâmicas para atualizar valores com unidades compatíveis. Confira as unidades antes de ligar.

Salvar memoriza as escolhas e a ordem das ferramentas neste dispositivo. As entradas permanecem na aba atual e não são salvas.
