সূত্র

a ≠ 0 সহ ax + b = 0 এর জন্য: x = −b ÷ a। ঢাল-ছেদক আকারে y = mx + c একটি সরলরেখার জন্য: ঢাল হলো m (উত্থান/অনুভূমিক দূরত্ব), y-ছেদক হলো c (x = 0 বিন্দুর মান), এবং x-ছেদক হলো −c ÷ m (যেখানে m ≠ 0, সেখানে x-এর মান y = 0)। যদি a = 0 হয়, তাহলে ax + b = 0 সমীকরণের কোনো সমাধান থাকে না, যদি না b-ও 0 হয়, সেক্ষেত্রে প্রতিটি x-ই একটি সমাধান।

সমাধান করা উদাহরণ

3x + 6 = 0: x = −6 ÷ 3 = −2। যাচাই: 3 × (−2) + 6 = 0। y = 2x + 3 রেখাটির জন্য: ঢাল হলো 2 (x-এর প্রতিটি 1 ধাপের জন্য y 2 বৃদ্ধি পায়), y-অক্ষকে ছেদক হলো 3, এবং x-অক্ষকে ছেদক হলো −3 ÷ 2 = −1.50। রেখাটি y-অক্ষকে (0, 3) বিন্দুতে এবং x-অক্ষকে (−1.50, 0) বিন্দুতে ছেদ করে।

প্রযোজ্যতা ও সীমাবদ্ধতা

এই পৃষ্ঠাটি এক চলকের একক রৈখিক সমীকরণ সমাধান করে এবং সরলরেখা বর্ণনা করে। এটি দ্বিঘাত সমীকরণ (দ্বিঘাত সমীকরণ ক্যালকুলেটর দেখুন), সমীকরণ জোট (সমীকরণ জোট ক্যালকুলেটর দেখুন), বা অসমতা সমাধান করে না — যদিও y = mx + c এর x-অক্ষকে ছেদকটি বলে দেয় যে mx + c এর চিহ্ন কোথায় পরিবর্তিত হয়। ইনপুট হলো সাধারণ সংখ্যা; ভগ্নাংশ অবশ্যই দশমিক হিসেবে লিখতে হবে, এবং খুব বড় বা ছোট সহগ প্রদর্শনে নির্ভুলতা হারাতে পারে, যদিও এর অন্তর্নিহিত পাটিগণিত স্ট্যান্ডার্ড ডাবল প্রিসিশন।

FAQ

যদি a = 0 হয় তাহলে কী হবে?

তাহলে সমীকরণটি হবে b = 0, যেখানে x নেই। যদি b, 0-ও হয়, তবে x-এর প্রতিটি মান এটিকে সিদ্ধ করে (সমীকরণটি একটি অভেদ)। যদি b, 0 না হয়, তবে x-এর কোনো মানই এটিকে সিদ্ধ করে না। শূন্য দিয়ে ভাগ করার পরিবর্তে কোন ক্ষেত্রটি প্রযোজ্য, তা পৃষ্ঠাটিতে বলা থাকে।

ঢাল আসলে কী বোঝায়?

উল্লম্ব পরিবর্তন ও অনুভূমিক পরিবর্তন: x যখন 1 পরিমাণ বৃদ্ধি পায়, তখন y কতটা পরিবর্তিত হয়। 2 ঢালের অর্থ হলো x-এর প্রতি ধাপে y, 2 একক উপরে ওঠে; −0.5 ঢালের অর্থ হলো x-এর প্রতি ধাপে y, আধা একক নিচে নামে। 0 ঢাল একটি অনুভূমিক রেখা নির্দেশ করে।

আমি x-ছেদক কীভাবে পড়ব?

এটি সেই বিন্দু যেখানে রেখাটি x-অক্ষকে ছেদ করে, অর্থাৎ যেখানে y = 0। y = 2x + 3 এর জন্য, 2x + 3 = 0 সমাধান করলে x = −1.50 পাওয়া যায় — যা সমীকরণ সমাধানকারীর গণনার মতোই, এবং এটি কোনো কাকতালীয় ঘটনা নয়: ছেদকগুলো হলো সমীকরণের সমাধান মাত্র।

আমি কি ভগ্নাংশ লিখতে পারি?

ভগ্নাংশগুলোকে দশমিক সংখ্যা হিসেবে লিখুন (1/2 কে 0.5 হিসেবে)। পৃষ্ঠাটি দুই দশমিক স্থান পর্যন্ত ফলাফল দেখায়; 1/3 এর মতো আবৃত দশমিক সংখ্যাগুলো 0.33 হিসেবে প্রদর্শিত হয়, তাই সঠিক ভগ্নাংশ গণনার জন্য ভগ্নাংশ রূপটি পাশে রাখুন।

ঢাল-ছেদক এবং আদর্শ রূপের মধ্যে পার্থক্য কী?

ঢাল-ছেদক রূপ y = mx + c সরাসরি ঢাল এবং y-ছেদক প্রকাশ করে। আদর্শ রূপ Ax + By = C হলো একই রেখার পুনর্বিন্যাস: m = −A ÷ B এবং c = C ÷ B (যখন B ≠ 0)। এই পৃষ্ঠাটি ঢাল-ছেদক রূপে কাজ করে।

এই যাচাই কেন গুরুত্বপূর্ণ?

সমাধানটি পুনরায় প্রতিস্থাপন করলে চিহ্নের ভুল ধরা পড়ে, যা রৈখিক সমীকরণে সবচেয়ে সাধারণ ভুল। 3x + 6 = 0 এর জন্য, x = −2 সঠিক কারণ 3(−2) + 6 = 0; x = 2 হলে 12 পাওয়া যেত, 0 নয়।
