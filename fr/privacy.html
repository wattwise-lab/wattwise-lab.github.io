Gardez le contrôle de vos données de calcul.

Fonctionnement 2026-10-30 effectif. Les calculatrices s'exécutent localement sans compte utilisateur ni base de données d'application CalcMintly.

Opérateur du site

CalcMintly est géré par un particulier. Pour toute correction concernant les calculatrices ou toute demande relative à la confidentialité, veuillez contacter hello@calcmintly.com. Veuillez ne pas inclure d'informations personnelles sensibles dans vos courriels.

Saisie et analyse du texte local

Les saisies, les instantanés de scénario et les liens vers l'espace de travail restent généralement en mémoire. Le planificateur de profit du commerçant dispose également d'une action « Enregistrer » explicite qui stocke son plan, y compris les hypothèses saisies, dans ce navigateur jusqu'à ce que vous l'effaciez. La fonction de saisie en langage naturel utilise les règles de texte locales ; votre texte n'est pas envoyé à un service AI. Le rechargement efface généralement les saisies. Un lien de calcul partagé peut restaurer les valeurs que vous avez saisies intentionnellement.

Préférences et comptage optionnel des appareils

La langue et les mises en page enregistrées utilisent le stockage local de ce navigateur. Les mises en page enregistrent les choix et l'ordre de la calculatrice, mais pas les données saisies. Le comptage des utilisations (optionnel et limité à l'appareil) est désactivé par défaut ; il enregistre uniquement le nombre de visites sur la calculatrice et est effacé lorsqu'il est désactivé. Ces données ne sont pas envoyées à CalcMintly.

Partage, exportations et impression

Les liens de mise en page contiennent uniquement les options d'outils. Les boutons de partage de calculs incluent les données sélectionnées dans le fragment URL ; toute personne recevant ce lien peut les lire. Les fichiers CSV et les rapports imprimés contiennent les valeurs que vous exportez. Veuillez les vérifier avant de les partager. Le partage des données de la calculatrice de santé est désactivé.

Hébergement et sites web externes

Le fournisseur d'hébergement peut traiter les adresses IP, les heures de requête, les détails du navigateur et les chemins demandés à des fins de livraison et de sécurité. Les fragments URL ne font pas partie des requêtes HTTP ordinaires. Les liens de référence tiers suivent leurs propres politiques de confidentialité.

Analyse, publicité et contact

L'analyse comportementale, la publicité et les cookies de suivi non essentiels ne sont pas activés. Aucune bannière de consentement n'est affichée pour un suivi inexistant. Les courriels que vous envoyez sont traités par les fournisseurs de messagerie ; évitez d'y inclure des informations financières ou de santé confidentielles. Utilisez l'adresse de contact pour toute demande relative à la confidentialité ou aux droits sur les données.

Contrôles des données locales

Les mises en page enregistrées, les préférences linguistiques et l'historique d'utilisation (facultatif) sont stockés dans ce navigateur. Utilisez ce bouton pour supprimer les données locales CalcMintly.

Les choix d’unité et de devise sont enregistrés uniquement après avoir sélectionné Mémoriser les choix. Ce réglage ne conserve ni nombres ni données de calcul. Effacer les données locales de CalcMintly supprime aussi ces choix.
