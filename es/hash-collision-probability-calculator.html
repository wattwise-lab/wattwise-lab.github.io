Probabilidad de colisión aproximada

—

Solo se utilizan funciones hash uniformes e independientes. Hasta 10,000 funciones hash utilizan el producto sin colisión en el espacio log; para cantidades mayores se utiliza la aproximación del cumpleaños. Un número de funciones hash superior al de salidas posibles garantiza una colisión. Esto no constituye una prueba de seguridad criptográfica ni un modelo de colisiones adversarias.

Fórmula

n es el contador de hash y b es el ancho en bits. Para n ≤ 10,000, P = 1 − ∏(1 − k/2^b), k = 0…n−1. Los contadores más grandes usan P ≈ 1 − exp[−n(n−1)/(2×2^b)]. Si n > 2^b, P = 1.
