Formel

Verwenden Sie L = B⁻¹(α/2;k,n−k+1) und U = B⁻¹(1−α/2;k+1,n−k). k ist die Anzahl der Erfolge und n die Anzahl der Versuche. Für das als Bruchteil c angegebene Konfidenzniveau gilt α = 1−c; B⁻¹ ist das Beta-Quantil. Beachten Sie die Randfälle k = 0 → L = 0 und k = n → U = 1.
