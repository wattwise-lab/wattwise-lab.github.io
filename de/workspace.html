DEIN RECHNER-ARBEITSPLATZ

Ihre Tools. Seite an Seite.

Wählen Sie einen Rechner, geben Sie Ihre Zahlen ein und vergleichen Sie. Bis zu vier Tools können gleichzeitig verwendet werden.

Drei einfache Schritte

  1. Fügen Sie einen Rechner anhand seines Namens oder Zwecks hinzu. Verwenden Sie „Ersetzen“ auf einer Karte, um ihn zu ändern.
  2. Bearbeiten Sie die Beispielzahlen. Jeder Rechner wird unabhängig aktualisiert.
  3. Verwenden Sie „Ergebnis senden“, um eine Zahl in eine andere Karte zu kopieren. Überprüfen Sie vorher die Einheiten; Werte bleiben nicht verknüpft.

Speichern merkt sich die Werkzeugauswahl und die Reihenfolge auf diesem Gerät. Eingaben bleiben im aktuellen Tab und werden nicht gespeichert.

Schnellstart

Vorgefertigtes Paar hinzufügen

Berechnungen werden in Ihrem Browser ausgeführt. Wechselkurse und Annahmen werden von Ihnen eingegeben. Öffnen Sie den vollständigen Rechner, um dessen Formeln und Einschränkungen einzusehen.

WERKZEUG AUSWÄHLEN

Rechner hinzufügen

Ergebnis übertragen

Wählen Sie Ergebnis, Zielrechner und Eingabe. Hierbei wird eine Zahl einmal kopiert; Einheiten werden nicht umgerechnet und Werkzeuge nicht verknüpft.
