明细

项目数值

每月 token 数 = 每月调用次数 × 每次调用的 token 数。价格按所填的每百万 token 单价计算。

概览

条形图按较大的费用项缩放，用于比较输入 token 与输出 token 各自占用的费用。

不同通话量的每月费用

场景数值

每行沿用所填的单次调用 token 数和单价，仅改变调用次数，因此费用与调用量成正比。

计算公式

每月费用 = 调用次数 ×（输入 token 数 × 输入单价 + 输出 token 数 × 输出单价）÷ 1,000,000，单价单位为 USD/百万 token。每次调用费用 = 每月费用 ÷ 调用次数。

计算示例

每次输入 2,500 token、输出 800 token，每月调用 100,000 次；每百万 token 的输入单价为 5 美元、输出单价为 20 美元。输入费用 = 100,000 × 2,500 × 5 ÷ 1,000,000 = 1,250 美元；输出费用 = 100,000 × 800 × 20 ÷ 1,000,000 = 1,600 美元。合计每月 2,850 美元，每次调用 0.0285 美元。此处价格仅作演示，请填写实际方案的价格。

适用范围与限制

所有价格均为可编辑的每百万 tokens 美元示例，不是提供商当前报价。零调用时月费为零，假设单次成本仍按 token 与价格计算；缓存、推理 tokens、折扣、其他模态、税费与限速需另行估算。

常见问题

如何计算？

每个调用的成本是输入tokens乘以输入价格加上输出tokens乘以输出价格，除以1,000,000；每次通话费用乘以每月通话次数就是每月总计。

默认价格是真实的提供商价格吗？

不。它们是示例输入。提供商的价格会根据型号和级别的不同而变化，因此请在使用结果之前输入您自己的计划或发票中的价格。

为什么产出成本常常大于投入成本？

每token的输出价格通常高于输入价格，并且长期输出加起来。细分表显示了拆分情况，以便您可以了解要优化哪一侧。

什么被排除？

缓存或折扣tokens、批量定价、重试、基础设施和员工时间。如果这些对您来说很重要，请单独添加它们，而不是将此总数视为全部拥有成本。

如何估算每次调用的tokens？

测量真实呼叫的样本：记录输入和输出token计数，对它们进行平均，并在提示改变后重新检查。几次简短测试调用的平均值通常会低估生产调用。

这准确地预测了我的账单吗？

不。这是根据您的平均值和价格进行的估计。将其与一个月的实际发票进行比较，然后调整 token 平均值或价格，直到模型跟踪实际情况。
