CSS کلیمپ اظہار

—

تیار کردہ CSS ایک ابتدائی قدر ہے۔ متعلقہ ٹیکسٹ یونٹس کو ترجیح دیں جہاں مناسب ہوں اور زوم، ٹیکسٹ اسکیلنگ اور اوور فلو کی جانچ کریں۔

منظر نامے کا موازنہ

اس ٹیب میں تین سنیپ شاٹس تک۔ ایک کو لوڈ کرنا موجودہ ان پٹس کی جگہ لے لیتا ہے۔

فارمولا

m = 100(f₁−f₀)/(v₁−v₀) اور b = f₀−mv₀/100 استعمال کریں۔ سیال کا سائز clamp(f₀, b + m×vw, f₁) ہے؛ f فونٹ کے سائز کو ظاہر کرتا ہے اور v ویوپورٹ کی چوڑائی کو ظاہر کرتا ہے۔

دو ویو پورٹ چوڑائیوں کے درمیان ایک لکیری CSS فونٹ پیمانہ بنائیں۔

کام کی مثال

کم از کم فونٹ سائز (px)
16
زیادہ سے زیادہ فونٹ سائز (px)
24
کم از کم ویو پورٹ چوڑائی (px)
400
ویو پورٹ کی زیادہ سے زیادہ چوڑائی (px)
1200
CSS کلیمپ اظہار
clamp(16px, calc(12px + 1vw), 24px)
ویو پورٹ گتانک
1 vw
پکسل انٹرسیپٹ
12 px
