Pince typographique fluide

Générer une échelle de police linéaire CSS entre deux largeurs de fenêtre.

Ajouter à l’espace de travail

Vos valeurs

Expression de limitation CSS

—

CSS généré est une valeur initiale. Privilégiez les unités de texte relatives lorsque cela est approprié et testez le zoom, la mise à l'échelle du texte et le débordement.

Comparaison de scénarios

Jusqu'à trois instantanés dans cet onglet. Le chargement d'un instantané remplace les entrées actuelles.

Formule

Utilisez m = 100(f₁−f₀)/(v₁−v₀) et b = f₀−mv₀/100. La taille fluide est clamp(f₀, b + m×vw, f₁) ; f désigne les tailles de police et v désigne les largeurs de la fenêtre d’affichage.
