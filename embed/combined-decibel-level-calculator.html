Formula

Use L = 10log₁₀[Σ10^(Lᵢ/10)]. Lᵢ are independent incoherent levels in dB, sharing the same reference, weighting and location. The combined level L uses the same basis.

Scope and limitations

All levels must use the same reference, weighting and observation location. Coherent sources require phase information.
