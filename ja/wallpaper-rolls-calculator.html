このタブには最大3つのスナップショットを保存できます。1つ読み込むと現在の入力が置き換えられます。

計算式

r = 0 の場合、カット長さは c = h+t です。r > 0 の場合は c = r ceil((h+t)/r) を使用します。ロールは N = ceil[ceil(P/w)/floor(L/c)] です。h は壁の高さ、t はトリム、r はパターンの繰り返し、P は壁の周囲、w はロールの幅、L はロールの長さで、すべて m で表されます。ceil は切り上げ、floor は切り捨てます。
