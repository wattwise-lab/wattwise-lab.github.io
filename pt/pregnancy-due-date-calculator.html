A idade gestacional atual é calculada em tempo real a partir do LMP inserido até a data atual, portanto, muda diariamente; a data prevista para o parto em si não muda depois que o LMP é fixado.

Fórmula

Data prevista para o parto = primeiro dia da última menstruação + 280 dias (40 semanas). Esta é a regra de Naegele. Assume-se um ciclo regular de 28 dias com ovulação no dia 14, razão pela qual a data aproximada da concepção é mostrada como LMP + 14 dias. Os limites dos trimestres mostrados são LMP + 14 semanas e LMP + 28 semanas.

Exemplo prático

Última menstruação 2026-01-01: data prevista para o parto = 2026-01-01 + 280 dias = 2026-10-08. A concepção aproximada (suposição de ciclo de 28 dias) é 2026-01-15. Na data de referência 2026-09-10, a idade gestacional é (2026-09-10 − 2026-01-01) = 252 dias = 36 semanas 0 dias, com 28 dias (4 semanas 0 dias) restantes até a data prevista para o parto. Use o exemplo de redefinição acima para reproduzir a data prevista para o parto; a idade gestacional hoje na página ativa é calculada a partir da data atual real.

Escopo e limitações

A regra de Naegele é uma estimativa baseada em duas suposições que muitas vezes não se verificam exatamente: um ciclo regular de 28 dias e ovulação no dia 14. Ciclos mais longos ou irregulares, datas LMP incertas e a datação por ultrassom podem alterar a estimativa, e a data real do parto varia de pessoa para pessoa — apenas uma minoria dos nascimentos ocorre exatamente na data estimada. Esta página não substitui os registros de cuidados pré-natais ou a datação clínica e não faz nenhuma afirmação sobre a saúde de qualquer gravidez.

FAQ

O que é a regra de Naegele?

Adicionar 280 dias (40 semanas) ao primeiro dia da última menstruação. É a regra padrão para estimar a data, não uma medida.

Por que a data real pode ser diferente?

Porque os ciclos variam: a ovulação nem sempre ocorre no dia 14, a duração dos ciclos varia e a própria data LMP pode ser incerta. A datação por ultrassom geralmente refina a estimativa.

E se meus ciclos forem mais longos que 28 dias?

Nesse caso, a ovulação provavelmente ocorreu depois do dia 14 e a data prevista para o parto pode ser posterior a esta estimativa. Esta página não ajusta a duração do ciclo — esse ajuste deve ser feito na datação clínica.

A data prevista significa que o bebê chegará nesse dia?

Não. É uma estimativa no centro de um intervalo; as datas reais de parto variam bastante em torno dela.

Meus dados estão armazenados?

Não. Este cálculo é executado localmente no seu navegador e os valores que você insere não são enviados para um banco de dados CalcMintly.

Devo usar isso para decisões médicas?

Não. Use os registros de cuidados pré-natais e o aconselhamento clínico para decisões médicas; esta página mostra apenas o cálculo da regra de Naegele.
